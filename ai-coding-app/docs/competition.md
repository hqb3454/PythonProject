# 参赛材料说明

## 作品定位

校园代码智能助手面向数据结构、算法和程序设计课程，帮助学生完成课程答疑、算法理解、代码生成、代码解释、Bug 修复和测试用例设计。作品不是单纯在 IDE 中安装工具，而是基于湛卢 IDE 的 AI Coding 能力开发出的独立可演示应用。

## 评审维度对齐

### 创新性

- 通过 MCP 把本地 RAG 知识库同时接入湛卢 IDE 和独立 Web 应用。
- 使用“向量召回 + cross-encoder 重排”的两阶段检索提升课程知识命中质量。
- 将课程知识、算法模板、代码调试和测试生成放在一个学习工作台内。

### AI Coding 能力运用

- 代码智能生成：生成 MCP Server、FastAPI 后端、Vue 前端和接口封装。
- 智能调试：定位 HTTP MCP transport、client list_tools 返回值等兼容问题。
- 代码评审：围绕接口边界、异常处理、降级模式和演示稳定性检查。
- Bug 修复：将二分查找、树遍历、排序等典型错误沉淀为演示流程。
- 单元测试：覆盖 stdio MCP、HTTP MCP、后端 API 和前端演示路径。
- 高阶能力：使用 MCP、RAG、本地模型、Skill/最佳实践文档形成开发范式。

### 技术实现

- 前端：Vue + Vite 工作台。
- 后端：FastAPI API 服务。
- 工具层：MCP Client 调用 HTTP MCP Server。
- 知识层：ChromaDB、本地 embedding 模型、本地 rerank 模型。
- 数据层：Markdown 课程和算法知识库。

### 应用价值

- 降低学生理解数据结构和算法的门槛。
- 为课程助教提供可扩充的课程知识库。
- 支持本地部署，适合课堂、机房或实验室内网环境。
- 可拓展到论文摘要、课程资料问答、实验报告辅助等校园场景。

### 展示与文档

- README 提供架构、模型路径、启动方式和演示脚本。
- Vue 工作台支持现场直接演示。
- 右侧引用面板展示来源文件、chunk 编号和重排分数，增强可信度。

### 加分项

- 本地 MCP + RAG 服务可被湛卢 IDE 和 Web 应用复用。
- 开发流程可沉淀为“垂直领域知识库 + MCP Server + AI Coding 应用”的最佳实践。

## 演示路线

1. 打开 Vue 工作台，确认 MCP 服务状态为已连接。
2. 课程答疑：询问“什么是二叉搜索树”。
3. 代码生成：生成二分查找或层序遍历代码。
4. Bug 修复：提交有边界错误的二分查找代码。
5. 测试生成：为快速排序生成测试用例。
6. 知识扩充：新增一篇 Markdown 文档并立即检索。
