# 数据结构 · 线性表（课程讲义摘要）

## 线性表的定义
- 线性表是**具有相同数据类型的 n 个数据元素的有限序列**，除首尾元素外每个元素有且仅有一个前驱和一个后继。
- 基本操作：初始化、销毁、插入、删除、按值查找、按位查找、求长度、判空、遍历。
- 线性表的两种存储结构：**顺序存储（顺序表）** 与 **链式存储（链表）**。

## 顺序表
- 用一组**地址连续**的存储单元依次存放，逻辑相邻即物理相邻。
- 特点：支持**随机访问**，第 i 个元素地址 = 首地址 + (i-1)×元素大小，按位查找 O(1)。
- 插入：需把第 i 个及之后的元素整体后移，平均移动 n/2 个元素，时间复杂度 O(n)。
- 删除：第 i 个之后的元素整体前移，平均移动 (n-1)/2 个，时间复杂度 O(n)。
- 空间：静态分配（数组，大小固定，溢出报错）与动态分配（malloc/realloc，可扩容但需搬移）。
- 优点：存储密度高、随机访问快；缺点：插入删除要搬移大量元素、需预先分配空间。

## 单链表
- 每个结点含数据域与指向后继的指针域，结点在内存中**不要求连续**。
- 引入**头结点**的好处：统一空表与非空表的处理，使第一个结点的插入删除与其他位置一致。
- 头指针 vs 头结点：头指针一定存在，指向第一个结点（有头结点时指向头结点）；头结点是可选的数据域为空（或存表长）的结点。
- 操作复杂度：按位查找 O(n)、按值查找 O(n)；**在给定结点后插入 O(1)**，但在给定结点前插入若不知道前驱仍是 O(n)（可"后插 + 交换数据"巧妙实现 O(1)）。
- 建立链表：头插法（得到的链表顺序与输入**相反**，常用于逆置）与尾插法（需维护尾指针，顺序一致）。

## 双链表
- 结点含 prior 与 next 两个指针，可双向遍历。
- 插入删除需同时修改四个指针，注意顺序：先处理新结点与前驱的关系，再处理与后继的关系（或先保存后继指针）。
- 优点：已知某结点时删除它自身是 O(1)（单链表必须找到前驱，O(n)）。

## 循环链表
- 循环单链表：尾结点 next 指向头结点；判空条件是头结点 next == 头结点（而非 NULL）。
- 只设尾指针时不需遍历即可访问头结点和尾结点，适合"合并两个线性表"与队列场景。
- 循环双链表：尾结点 next 指头结点，头结点 prior 指尾结点，判空条件为两者均成立。

## 静态链表
- 用数组模拟链表，结点含数据域与游标 cur（下一个结点的下标），以 cur == 0（或 -1）表示结束。
- 适用于**不支持指针的语言**（如早期 BASIC、FORTRAN）或需一次性分配空间的嵌入式场景。
- 需要额外维护"空闲结点链表"来分配与回收空间。

## 顺序表 vs 链表
| 对比项 | 顺序表 | 链表 |
|---|---|---|
| 存储 | 连续（数组） | 离散（指针串起来） |
| 随机访问 | O(1) | O(n) |
| 插入删除（已知位置） | O(n)（搬移） | O(1)（改指针） |
| 查找（按值） | 有序时可二分 O(log n) | 只能顺序 O(n) |
| 空间开销 | 无指针域，存储密度高 | 每个结点多一个指针 |
| 分配方式 | 需连续大空间，易碎片 | 零散空间即可，灵活 |

## 线性表的应用
- 一元多项式的表示与相加：顺序表适合稠密多项式（按指数下标直接存系数），链表适合稀疏多项式（只存非零项，合并时指数相同则系数相加）。
- 集合的并、交、差运算。
- 大整数运算、约瑟夫环问题（循环链表）。

## 重点结论
- 选择依据：**查询多、长度变化少 → 顺序表；插入删除多、长度变化大 → 链表**。
- 头结点是"哨兵"，是简化边界处理的标准手法，也避免了在第一个位置插入时需要特殊判断。
- 头插法建表天然实现逆序，是链表逆置的常用技巧。
- 双链表在"删除指定结点"上比单链表有优势，但每个结点多占一个指针空间。

## 常见考题
- 在带头结点 / 不带头结点的单链表第 i 个位置插入结点，写出指针修改顺序并说明两者差异。
- 设计 O(n) 的算法：链表逆置（三指针法）、删除所有值为 x 的结点、找倒数第 k 个结点（双指针）。
- 判断链表是否有环（快慢指针）、求环的入口、判断两链表是否相交。
- 用顺序表或链表实现多项式相加，并分析时间与空间复杂度。
- 给定操作序列，分析顺序表插入/删除的平均移动元素个数。
