# 输入输出管理（课程讲义摘要）

## I/O 系统的层次结构
自上而下五层，每层向上提供统一接口、向下屏蔽差异：
1. **用户层 I/O 软件**：库函数（printf/fread）、SPOOLing、用户进程调用接口；
2. **设备独立性软件**：设备命名、保护、缓冲、设备分配、逻辑设备到物理设备的映射（LUT）；
3. **设备驱动程序**：与硬件直接相关，把上层请求翻译成设备命令，设置寄存器、检查状态；
4. **中断处理程序**：I/O 完成后唤醒阻塞的驱动进程，处于 I/O 系统的底层但由 CPU 直接响应；
5. **硬件设备**：设备控制器与机械部件（设备本身与控制器分离，控制器负责电气转换）。

- 设备独立性（设备无关性）：用户程序用逻辑设备名请求设备，实际映射由 OS 完成，换设备不用改程序。

## I/O 控制方式
| 方式 | 数据流向 | CPU 参与 | 适用 |
|---|---|---|---|
| 程序直接控制 | 设备↔CPU↔内存 | 全程轮询，CPU 与设备串行 | 极简单设备 |
| 中断驱动 | 设备↔CPU↔内存 | 每字/字节中断一次 | 中低速字符设备 |
| DMA | 设备↔内存（直接） | 仅在预处理与后处理 | 高速块设备 |
| 通道控制 | 设备↔内存（通道程序） | 仅启动与结束 | 大型机，可管多台设备 |

- 中断方式的改进：CPU 与设备可并行，但每字节都要中断，对块设备仍不划算，因此出现 DMA。

## 缓冲技术
- 引入缓冲的原因：缓和 CPU 与 I/O 的速度矛盾、减少中断频率、提高 CPU 与设备的并行度。
- 实现方式：
  - 硬件缓冲（设备控制器内的寄存器/小 FIFO）；
  - 单缓冲：一块缓冲区，处理一块时不能读入下一块，平均处理时间 = max(C, T) + M；
  - 双缓冲：两块交替，C 与 T 可并行，平均处理时间 ≈ max(C, T)；
  - 循环缓冲：多个缓冲区组成环形，in/out 指针管理；
  - **缓冲池**：公共缓冲区分成空缓冲队列、输入队列、输出队列，多个进程共享，最灵活。
- C = CPU 处理一块数据的时间，T = 从设备读入一块的时间，M = 把缓冲区数据送到用户区的时间。

## 设备分配
- 设备类型：独占设备（打印机，需独占）、共享设备（磁盘，可交替服务）、虚拟设备（SPOOLing 虚拟出来的）。
- 分配算法：先来先服务 + 优先级高者优先（同优先级按 FCFS）。
- 分配安全性：安全分配（进程请求设备后阻塞，直到用完才唤醒，不会死锁但不并行）与不安全分配（可继续请求其他设备，可能死锁）。
- 分配数据结构：设备控制表 DCT、控制器控制表 COCT、通道控制表 CHCT、系统设备表 SDT。
- **SPOOLing（假脱机）**：把独占设备改造成共享设备。核心是在磁盘上开辟"输入井/输出井"，由输出进程负责真正打印，用户进程只需把数据写入输出井即可返回。**SPOOLing 是典型的"空间换时间"，也是虚拟设备技术的基础**。

## 设备驱动程序
- 功能：接收上层命令、检查请求合法性、向设备控制器发命令、响应中断、维护设备状态。
- 特点：与硬件密切相关，是 OS 中唯一知道设备寄存器细节的部分；通常用汇编/C 编写，运行在内核态。
- 驱动程序处理流程：接收请求 → 检查状态 → 启动设备 → 阻塞等待中断 → 中断唤醒 → 返回结果。

## 磁盘调度算法
| 算法 | 规则 | 特点 |
|---|---|---|
| FCFS 先来先服务 | 按请求次序 | 公平但寻道距离大 |
| SSTF 最短寻道优先 | 选离当前磁头最近的 | 性能好，但远处请求可能"饥饿" |
| SCAN 电梯算法 | 单向移动到端点再反向 | 无饥饿，但两端响应不均 |
| LOOK | 移到最远请求处即反向 | SCAN 的改进，减少空跑 |
| CSCAN 循环扫描 | 单向移动，到端点立即回到起点 | 响应最均匀，适合负载重的系统 |
| CLOOK | CSCAN 的 LOOK 改进版 | 同上，减少空跑 |

- 评价指标：平均寻道长度（总移动磁道数 / 请求数）。
- 减少延迟的其他手段：交替编号（扇区编号错开，给磁头留出处理时间）、错位命名（不同盘面扇区错开）、磁盘高速缓存、提前读与延迟写。

## 磁盘管理
- 磁盘初始化：低级格式化（划分扇区，含校验字段）→ 分区 → 逻辑格式化（建立文件系统）。
- 引导块：存放自举程序，开机时 ROM 中的自举装入程序把引导块读入内存。
- 坏块处理：简单磁盘由控制器维护坏块表并替换备用块；复杂磁盘由 OS 逻辑格式化时标记坏块，文件系统不再使用。

## 重点结论
- 引入缓冲的核心目的不是"提速"，而是**缓和速度差异、减少中断次数、提高并行度**。
- 单缓冲与双缓冲的平均处理时间公式是必考计算题：单缓冲 max(C,T)+M，双缓冲 max(C,T)。
- SPOOLing 让多个进程"同时"使用独占设备，用户进程感觉打印瞬间完成，实际由后台输出进程排队打印。
- SSTF 有饥饿问题，SCAN 系列解决了饥饿；CSCAN 让各位置请求的等待时间更均匀。

## 常见考题
- 给定磁头当前位置与请求序列，用 FCFS / SSTF / SCAN / CSCAN 计算移动磁道总数与平均寻道长度。
- 已知 T、C、M，计算单缓冲与双缓冲下处理 n 块数据的总时间。
- 说明 SPOOLing 的组成（输入井/输出井 + 输入/输出缓冲区 + 输入/输出进程）与工作原理。
- 比较四种 I/O 控制方式对 CPU 的占用程度。
