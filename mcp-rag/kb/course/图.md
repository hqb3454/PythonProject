# 数据结构 · 图（课程讲义摘要）

## 图的基本概念
- 图 G = (V, E)，V 是顶点集，E 是边集。**线性表可以是空表、树可以是空树，但图不能没有顶点**（顶点集非空，边集可为空）。
- 有向图 / 无向图：边是否有方向；无向图中 `(v,w)` 与 `(w,v)` 是同一条边。
- 度：无向图顶点的度 = 关联的边数，握手定理 `Σdeg(v) = 2|E|`；有向图分入度与出度，`Σ入度 = Σ出度 = |E|`。
- 完全图：无向完全图有 `n(n-1)/2` 条边，有向完全图有 `n(n-1)` 条边。
- 连通性：无向图中两顶点有路径则连通；**连通图**任意两点连通；连通分量是无向图的极大连通子图。
- 强连通（有向图）：v 到 w 且 w 到 v 都有路径；强连通分量同理。
- 生成树：连通图的包含全部顶点的极小连通子图，n 个顶点 n-1 条边；**生成森林**对应非连通图。
- 网：带权图；路径长度在无网上是边数，在网上是权值之和。
- 简单路径（顶点不重复）与简单回路；回路（环）是起点与终点相同的路径。

## 图的存储结构
| 结构 | 空间 | 适用 | 查找邻接点 |
|---|---|---|---|
| 邻接矩阵 | O(n²) | 稠密图，快速判两点是否有边 | O(n) |
| 邻接表 | O(n+e) | 稀疏图，最常用 | 扫描对应链表 |
| 十字链表 | O(n+e) | 有向图，方便同时找入边与出边 | 链表 |
| 邻接多重表 | O(n+e) | 无向图，方便删边 | 链表 |

- 邻接矩阵：无向图的矩阵对称，可只存上三角节省空间；第 i 行非零元素个数 = 顶点 i 的出度（有向图）。
- 邻接表：每个顶点一个单链表存其邻接顶点；**无向图每条边存两次**，有向图只存一次（出边表；求入度不方便，可建逆邻接表）。
- 空间权衡：稀疏图用矩阵会浪费大量空间（n² 个格子大部分是 0）。

## 图的遍历
- **广度优先 BFS**：用队列 + 访问标记数组 visited；先访问顶点，再依次访问其所有未访问邻接点。
  - 时间：邻接矩阵 O(n²)，邻接表 O(n+e)；空间 O(n)。
  - 应用：求无权图的单源最短路径、判断连通性、求连通分量。
  - BFS 生成树的高度 ≤ DFS 生成树高度（BFS 是按层扩散，得到的路径最短）。
- **深度优先 DFS**：递归或显式栈，一条路走到头再回溯；需 visited 标记避免重复。
  - 时间同 BFS；空间 O(n)（递归栈）。
  - 应用：判断是否有环（无向图遇已访问且非父结点即有环；有向图用递归栈上的标记 + 回边）、拓扑排序、求连通分量、求割点与桥。
- 遍历序列不唯一：邻接点的存储次序不同会得到不同的 BFS/DFS 序列。

## 最小生成树 MST
- 定义：连通带权图中包含全部顶点、边权之和最小的生成树；**权值互不相等时 MST 唯一**，权值相同可能不唯一。
- 性质：n 个顶点、n-1 条边、无环；Kruskal 与 Prim 都基于贪心，都能得到最优解。
- **Prim 算法**：从某点开始，每次选一条连接"已选集合"与"未选集合"的最小边，加入一个顶点；适合**稠密图**；用邻接矩阵 + 数组实现 O(n²)，用堆优化 O(e log n)。
- **Kruskal 算法**：按边权从小到大排序，若不形成环（并查集判断）则加入；适合**稀疏图**；时间 O(e log e)（排序主导）。
- 区别记忆：Prim 是"加点"，Kruskal 是"加边"；Prim 与顶点数相关，Kruskal 与边数相关。

## 最短路径
- **BFS 求无权图单源最短**：逐层扩散，首次到达即最短。
- **Dijkstra（单源，边权非负）**：维护 dist 数组，每轮选未确定中 dist 最小的顶点并松弛其邻接边；
  - 朴素 O(n²)（适合稠密图），堆优化 O(e log n)（适合稀疏图）；
  - **不能处理负权边**（已确定的顶点可能后续被更短路径更新，贪心失效）。
- **Floyd（多源，全对）**：三重循环动态规划，`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`；时间 O(n³)，空间 O(n²)；可处理负权边但**不能有负权回路**。
- **Bellman-Ford（单源，可含负权）**：对所有边松弛 n-1 轮，时间 O(ne)；可检测负权回路（第 n 轮仍能松弛则有负环）；SPFA 是其队列优化版。
- 对比：Dijkstra 快但要求非负权；Bellman-Ford 慢但通用；Floyd 一次求所有点对，适合 n 较小的场景。

## 有向无环图 DAG 的应用
- **拓扑排序**：
  - 步骤：① 选一个入度为 0 的顶点输出；② 删除它及其所有出边；③ 重复直到无顶点。
  - 若输出的顶点数 < n，说明图中**存在环**，无法拓扑排序。
  - 用队列实现：初始把所有入度为 0 的顶点入队，出队时把后继顶点入度减 1，减到 0 再入队；时间 O(n+e)。
  - 拓扑序列可能不唯一；AOV 网（用顶点表示活动、边表示先后关系）的拓扑序列代表一个可行的执行顺序。
- **关键路径 AOE 网**：顶点表示事件、有向边表示活动、边权为活动持续时间。
  - 事件最早发生时间 ve（从前向后取 max）、最迟发生时间 vl（从后向前取 min）；
  - 活动最早开始 e(i) = ve(起点)、最迟开始 l(i) = vl(终点) - 活动时长；
  - **e(i) == l(i) 的活动为关键活动**，关键活动组成的从源点到汇点的路径即关键路径，其长度决定整个工程的最短完成时间。
  - 注意：关键路径可能不止一条，缩短工期必须同时缩短所有关键路径上的活动。

## 重点结论
- 图的顶点集不能为空，这是与线性表、树的重要区别（易考判断题）。
- 邻接矩阵适合稠密图与"频繁判断两点是否有边"；邻接表适合稀疏图与"遍历某点所有邻接点"。
- Dijkstra 遇到负权边会出错，此时应换 Bellman-Ford；若有负权回路，则最短路径无解（可无限小）。
- 拓扑排序是判断有向图是否有环的标准方法；关键路径建立在拓扑排序（ve）与逆拓扑排序（vl）之上。
- 最小生成树保证"总权值最小"，最短路径保证"两点间距离最小"，两者**目标不同**，不可混淆。

## 常见考题
- 给定图的邻接表，写出从某点出发的 BFS 与 DFS 遍历序列（注意邻接点顺序）。
- 用 Prim 或 Kruskal 手工求最小生成树，写出加边顺序与最终权值和。
- 用 Dijkstra 手工求单源最短路径，写出每轮确定顶点的过程。
- 给定 AOV 网，写出所有可能的拓扑序列并判断是否有环。
- 给定 AOE 网，求 ve/vl、找出关键活动与关键路径，并计算工程最短工期。
