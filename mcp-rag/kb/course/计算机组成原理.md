# 计算机组成原理（课程讲义摘要）

## 存储层次结构
- 金字塔：寄存器 → Cache（SRAM）→ 主存（DRAM）→ SSD/磁盘 → 磁带/归档。
- 越往上速度越快、容量越小、单价越贵；层次间以"块/页"为单位搬运。
- 局部性原理是 Cache 有效的前提：时间局部性（刚访问的还会再访问）+ 空间局部性（附近地址大概率被访问）。

## Cache
- 三种映射：直接映射（每组1行，硬件简单、冲突多）/ 组相联（折中）/ 全相联（任意行，查找贵）。
- 写策略：写直达（同时写 Cache 和内存，一致但慢）vs 写回（只写 Cache，替换时才写回内存，快但复杂，需脏位）。
- 平均访存时间 = 命中时间 + 缺失率 × 缺失代价；优化核心永远是降缺失率。
- 替换常用 LRU（Cache 行数少，硬件可实现）。

## 指令流水线
- 五段经典流水线：取指 IF → 译码 ID → 执行 EX → 访存 MEM → 写回 WB。
- 吞吐率提升来自时间并行；单条指令时间不变，但每周期可完成约 1 条。
- 三种冒险：
  - 结构冒险（部件冲突）→ 增加资源/分相位；
  - 数据冒险（后指令依赖前指令结果）→ 转发/旁路、插入气泡；
  - 控制冒险（分支改变 PC）→ 分支预测（动态预测准确率可达 95%+）。

## 数据表示
- 补码：加法器同时处理加减，0 唯一；n 位补码范围 -2^(n-1) ~ 2^(n-1)-1。
- IEEE 754 单精度：1 符号 + 8 阶码 + 23 尾数；阶码用移码（偏置 127），尾数隐含前导 1。
- 特殊值：全 0 阶码（非规格化数/0）、全 1 阶码（NaN/无穷）。

## 重点结论
- Cache 对程序员透明但影响巨大：按行遍历二维数组远快于按列（空间局部性）。
- 数据冒险靠"转发"消除大部分气泡；load-use 冒险仍需 1 个气泡。
- 浮点比较不能用 ==（精度误差），应比较差的绝对值是否小于阈值。
- 补码的关键性质：[-x]补 = ~x + 1；减法即补码加法。

## 常见考题
- 给定主存地址位数与 Cache 结构（行数、块大小、映射方式），计算标记/组号/偏移各占几位。
- 计算 Cache 缺失率与平均访存时间；比较写直达与写回的总写次数。
- 识别给定指令序列中的冒险类型并写出解决方案。
- 手工转换：十进制 ↔ 补码十六进制；写出 3.75 或 -0.5 的 IEEE 754 表示。
