# 第 1 章：算法与数据结构基础（课程讲义摘要）

本课程讲解数据结构与算法基础，要求学生掌握：
- 栈（Stack）：后进先出，适合括号匹配、表达式求值；
- 队列（Queue）：先进先出，适合广度优先搜索（BFS）与任务调度；
- 链表（Linked List）：插入删除方便、随机访问 O(n)；
- 树（Tree）：二叉树、二叉搜索树的基本性质；
- 时间复杂度与大 O 记号：衡量算法随输入规模增长的趋势。

## 考试重点
- 能写出栈、队列的数组/链表实现；
- 能根据场景选择合适的数据结构；
- 会计算常见算法的时间复杂度，如遍历 O(n)、二分 O(log n)、排序（快排平均 O(n log n)）。
