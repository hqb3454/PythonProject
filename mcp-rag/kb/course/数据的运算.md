# 数据的运算（课程讲义摘要）

## 定点数的表示
- 原码：符号位 + 绝对值，0 有两种表示（+0 / -0），加减运算需判符号，硬件不友好。
- 反码：负数逐位取反，仍有两个 0，仅作求补码的中间步骤。
- 补码：现代机器统一用补码存整数。n 位补码范围 `-2^(n-1) ~ 2^(n-1)-1`；0 唯一；符号位参与运算。
- 移码：补码符号位取反，常用于浮点数阶码，便于直接比较大小。
- 关键性质：`[-x]补 = ~[x]补 + 1`（连符号位一起取反再加 1）。

## 补码加减法与溢出判断
- 公式：`[x+y]补 = [x]补 + [y]补`，`[x-y]补 = [x]补 + [-y]补`，减法全部转成加法，一套加法器搞定。
- 三种溢出判别法：
  - 单符号位：两操作数同号、结果异号 → 溢出。
  - 双符号位（变形补码）：结果符号位为 `01` 正溢、`10` 负溢，`00`/`11` 正常。
  - 进位判别：符号位进位 `Cs` 与最高数值位进位 `C1` 异或，结果为 1 则溢出。
- 注意：只有同号相加 / 异号相减才可能溢出，异号相加不会溢出。

## 移位运算
- 算术移位（有符号数）：左移补 0、右移补符号位，等价于乘 / 除 2（补码右移为向下取整）。
- 逻辑移位（无符号数）：左右都补 0。
- 循环移位：移出位回卷，常用于多字长拼接与位操作。

## 定点乘法与除法
- 原码一位乘：符号位单独异或，数值部分做「加法 + 右移」n 次，由乘数位决定加 0 还是加被乘数。
- 补码一位乘（Booth 算法）：看相邻两位 `(y_i, y_{i+1})`：00/11 只右移；01 加 `[x]补`；10 加 `[-x]补`。能统一处理负数。
- 原码除法（加减交替法，不恢复余数）：余数为正 → 商 1、余数左移减除数；余数为负 → 商 0、余数左移加除数。
- 除法第一步必须先判「被除数 < 除数」，否则直接溢出。

## 浮点数与机器实现
- IEEE 754 单精度：1 位符号 S + 8 位阶码 E（偏置 127）+ 23 位尾数 M（隐含前导 1）。
- 真值 = `(-1)^S × (1.M) × 2^(E-127)`；阶码全 0 是非规格化数，全 1 是 ∞ / NaN。
- 双精度：1 + 11（偏置 1023）+ 52。

### 浮点加减法（机器实现的五步）
1. **对阶**：小阶向大阶看齐，尾数右移（右移会丢失低位精度）。
2. **尾数加减**：按定点补码加减法运算。
3. **规格化**：左规（尾数左移、阶码减）或右规（尾数右移、阶码加），使尾数回到 `1.M` 形式。
4. **舍入**：就近舍入 / 朝 0 / 朝 +∞ / 朝 -∞（默认就近舍入到偶数）。
5. **溢出判断**：阶码上溢记 ∞、下溢记 0（按机器零处理）。

### 浮点乘除法
- 乘法：阶码相加再减偏置，尾数相乘，然后规格化 + 舍入。
- 除法：阶码相减再加偏置，尾数相除。

## 重点结论
- 补码让加减法统一，移码让阶码比较变简单，这是运算器硬件设计的核心技巧。
- 浮点运算**不满足结合律**：`(a+b)+c ≠ a+(b+c)`，因为对阶会丢精度，大数吃小数是典型现象。
- 浮点比较不能用 `==`，应判断 `abs(a-b) < eps`。
- 溢出是"结果超出表示范围"，与进位不同：进位是 unsigned 的第 n+1 位，溢出是 signed 的结果错误。

## 常见考题
- 写出 -0.75、13.625 的 IEEE 754 单精度十六进制表示。
- 用变形补码判断两数相加是否溢出，并写出双符号位结果。
- 手工演算 Booth 算法的 4 次迭代过程。
- 给定两个浮点数的阶码尾数，写出对阶、尾数相加、规格化后的最终结果。
