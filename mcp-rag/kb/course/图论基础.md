# 图论基础（课程讲义摘要）

## 图的表示
- 邻接矩阵：O(V²) 空间，查边 O(1)，适合稠密图；邻接表：O(V+E) 空间，适合稀疏图（大部分实际场景）。
- 有向/无向、带权/无权；连通分量、度数（入度/出度）。

## BFS 与 DFS
- BFS（队列）：按层扩展，**无权图最短路**；visited 入队时标记而非出队时标记以防重复入队。
- DFS（栈/递归）：深挖到底再回溯；是拓扑排序、割点桥、连通分量的基础。
- 递归 DFS 注意爆栈：深图可改显式栈或放宽递归限制。

## 最短路
- Dijkstra：**非负权**单源最短路，贪心+优先队列，O(E log V)；不能处理负权边。
- Bellman-Ford：可处理负权、可检测负环，O(VE)；SPFA 是其队列优化（最坏仍 O(VE)）。
- Floyd：多源最短路，三重循环 dp[i][j] = min(dp[i][j], dp[i][k]+dp[i][k][j])，O(V³)，实现最短。
- 网络流/差分约束等进阶问题的建模常以最短路为子模块。

## 拓扑排序
- 仅适用于 **DAG（有向无环图）**；方法：反复取入度为 0 的点，删除其出边。
- 用途：任务依赖/课程先修/编译顺序；同时可用于检测有向图是否有环（能否排满全部节点）。

## 并查集（Union-Find）
- 两个操作：find（找根）+ union（合并集合）；路径压缩 + 按秩合并后，单次操作近似 O(1)。
- 应用：连通分量个数、Kruskal 最小生成树的环检测（两端点已同集合则该边会成环，跳过）。
- 最小生成树：Kruskal（排序边+并查集，O(E log E)）适合稀疏图；Prim 适合稠密图。

## 重点结论
- 无权图最短路用 BFS 就够，不要用 Dijkstra"杀鸡用牛刀"。
- Dijkstra 出队的点不再更新（贪心依据是非负权下当前最短即为最终最短）；这正是负权失效的原因。
- 拓扑序不唯一；存在环的图没有拓扑序。
- 并查集不能删点/删边（只合并），如需撤销用按秩合并的 rollback 版本。

## 常见考题
- 手算 Dijkstra 从某源点出发的 dist 数组变化过程。
- 判断课程先修关系能否完成（拓扑排序判环）。
- 用 Kruskal 求 MST：写出选边顺序与跳过的边。
- 岛屿数量类题：网格视为图，DFS/BFS 数连通分量。
