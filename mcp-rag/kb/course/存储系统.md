# 存储系统（课程讲义摘要）

## 存储层次结构
- 金字塔：寄存器 → Cache（SRAM）→ 主存（DRAM）→ 固态/磁盘 → 磁带/归档。
- 越往上速度越快、容量越小、每位成本越高；层次之间以「块 / 页」为单位搬运。
- 局部性原理是层次结构成立的前提：时间局部性（刚访问的还会再访问）+ 空间局部性（相邻地址大概率被访问）。

## 半导体存储芯片
- SRAM：触发器存信息，速度快、集成度低、功耗大，用于 Cache。
- DRAM：电容存信息，需**定时刷新**（集中式 / 分散式 / 异步式），用于主存。
- DRAM 的地址复用：行地址、列地址分时送，引脚数减半；刷新按行进行，不占用正常读写周期时可"透明刷新"。
- ROM：MROM / PROM / EPROM / EEPROM / Flash，断电不丢失；SSD 基于 Flash，有擦写次数限制与写放大问题。

## 主存与 CPU 的连接
- 位扩展：多片芯片并联增加字长；字扩展：增加芯片数量扩大容量；常两者结合。
- 地址分配用片选信号（线选法 / 全译码 / 部分译码）。
- 多模块存储器：单体多字（一次读多个字）与多体并行（低位交叉编址，流水线式轮流启动，带宽近似翻倍）。

## Cache 工作原理
- 三种映射方式：
  - 直接映射：主存块固定映射到唯一 Cache 行，硬件最简单，冲突缺失多。
  - 全相联：可放任意行，冲突最少，但需并行比较所有行，成本高。
  - 组相联：组内全相联、组间直接映射，是实际机器的主流折中方案。
- 地址划分（组相联）：`标记 Tag | 组号 | 块内偏移`。
- 替换算法：随机 / FIFO / **LRU**（最常用）/ LFU；Cache 行数少，LRU 可用计数器或栈硬件实现。
- 写策略：
  - 写直达：同时写 Cache 与主存，一致性好但写速度慢。
  - 写回：只写 Cache，替换时才写回主存，需**脏位**标记；写速度快但一致性复杂。
  - 写缺失时可选「写分配」（调入 Cache 再写）或「非写分配」（直接写主存）。
- 性能公式：`平均访存时间 = 命中时间 + 缺失率 × 缺失代价`。
- 三种缺失（3C 模型）：强制缺失（首次访问）/ 容量缺失（Cache 装不下）/ 冲突缺失（映射冲突）。

## 虚拟存储器
- 页式虚存：虚拟地址 = 虚页号 + 页内偏移，通过页表映射到物理页框。
- 页表项含：有效位（是否在内存）、物理页框号、脏位、访问位、权限位。
- **TLB（快表）**：页表的高速缓存，采用相联存储器，命中可省去一次主存查页表；未命中才访问主存页表并更新 TLB。
- 地址转换流程：CPU 给虚地址 → 查 TLB（命中得页框号）→ 未命中查主存页表 → 形成实地址访问 Cache / 主存。
- 段式与段页式：段式便于共享和保护（按逻辑单位），段页式先分段再分页，兼顾两者优点。

## 重点结论
- Cache 对程序员透明但影响巨大：按行遍历二维数组远快于按列（空间局部性）。
- 数组合并、循环交换、分块（blocking）都能显著降低缺失率。
- TLB 未命中的代价比 Cache 未命中更高，因为它可能额外引发多次主存访问。
- 写回 + 写分配是最常见组合；I/O 设备用 DMA 直接访问主存时会引发 Cache 一致性问题，需软件刷新或用一致性协议。

## 常见考题
- 给定主存容量、Cache 行数、块大小与映射方式，计算 Tag / 组号 / 块内偏移各占几位。
- 计算缺失率与平均访存时间，比较写直达与写回的总写内存次数。
- 给定访存序列，模拟 LRU / FIFO 替换过程并统计命中次数。
- 已知页表与 TLB 命中率，计算一次地址转换的平均访存时间。
