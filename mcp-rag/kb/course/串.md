# 数据结构 · 串（课程讲义摘要）

## 串的基本概念
- 串（字符串）是**由零个或多个字符组成的有限序列**，记为 `S = "a1a2...an"`，n 为串的长度；n = 0 时为空串。
- 子串：串中任意个**连续**字符组成的子序列；主串中包含子串时，子串第一次出现的位置称为其在主串中的位置（通常从 1 开始计）。
- 空格串 ≠ 空串：空格串长度 > 0，空串长度为 0。
- 串相等：长度相同且对应位置字符完全相同。
- 串与线性表的区别：串的数据对象限定为字符集；串的基本操作以"**整体**"（子串）为对象，而线性表多以"单个元素"为对象。

## 串的存储结构
- 定长顺序存储：用固定长度数组，超出部分截断；可在下标 0 处存放长度（更便捷，Pascal 风格）或用 `\0` 结尾（C 风格，求长度需 O(n)）。
- 堆分配存储：运行时用 malloc 动态分配，灵活但需管理内存。
- 块链存储：用链表存串，每个结点可存多个字符（提高存储密度），最后一个结点不满时用特殊字符填充；适合频繁插入删除但整体上较少使用。

## 串的基本操作
- 赋值 StrAssign、复制 StrCopy、判空、比较 StrCompare、求长 StrLength、连接 Concat、
  求子串 SubString、定位 Index（模式匹配）、替换 Replace、插入、删除。
- 串比较规则：从第一个字符起逐位比较 ASCII/Unicode 码值，第一个不同字符决定大小；若前面都相同则**长的串更大**。

## 朴素模式匹配（BF 算法）
- 思路：主串指针 i 与模式串指针 j 从起点开始逐位比较；失配时 **i 回溯到本次起始位置的下一位**（i = i - j + 2），j 回到 1。
- 时间复杂度：最坏 O(n×m)，如主串 "aaaa...ab" 匹配模式 "aaaab"，每趟都在最后一位失配。
- 优点：思路直观、无需预处理；缺点：回溯造成大量重复比较。

## KMP 算法
- 核心思想：失配时**主串指针 i 不回溯**，只按模式串自身的"最长相等前后缀"信息移动 j，使匹配复杂度降到 O(n+m)。
- 前缀与后缀：对模式串 `P[1..j]`，其真前缀为不含最后一个字符的所有前缀，真后缀为不含第一个字符的所有后缀。
- **next 数组**：`next[j]` 表示当 `P[j]` 与主串失配时，j 应回退到的位置；即 `P[1..j-1]` 的最长相等真前后缀长度 + 1。
  - 约定 `next[1] = 0`（第一位失配则主串指针右移）。
  - 递推求法：若 `P[j] == P[next[j]]` 则 `next[j+1] = next[j] + 1`，否则令 `j = next[j]` 继续回退比较。
- 匹配过程：i 与 j 比较，相等则双双前进；失配时 `j = next[j]`（若 j == 0 则 i++ 且 j = 1）；当 j 超过模式长度即匹配成功，位置 = i - 模式长度。
- **nextval 改进**：若 `P[j] == P[next[j]]`，则这次比较注定也失败，令 `nextval[j] = nextval[next[j]]`，跳过无效比较。
- 时间复杂度：求 next O(m)，匹配 O(n)，总计 O(n+m)。

## next 数组计算示例
模式串 `abaabcac` 的 next（从 1 开始）为：`0 1 1 2 2 3 1 2`。
- 计算要点：next[j] 只与模式串前 j-1 个字符有关，与主串无关——这是 KMP 能够预处理的前提。

## 串的应用
- 文本编辑器的查找/替换、拼写检查。
- 生物信息学中的 DNA 序列匹配（ATCG 构成的"串"）。
- 编译器的词法分析（关键字、标识符识别）。
- 网络入侵检测、敏感词过滤（AC 自动机是 KMP 在多模式上的推广）。
- 字符串哈希（Rabin-Karp 算法）：用滚动哈希把串匹配降到平均 O(n+m)，适合多模式与大规模文本。

## 重点结论
- KMP 的关键洞察是"**模式串自身包含了足够的信息**"，主串不必回头。
- next 数组只依赖模式串，因此可以一次预处理、多次匹配（同一模式串匹配多个文本时优势明显）。
- 朴素算法在实际中往往够用（随机文本下失配通常发生在前几个字符），KMP 的价值在于最坏情况保证。
- 求 next 时最常见的错误是把"最长相等真前后缀长度"与 next 值混淆（next = 长度 + 1）。
- KMP 处理的是**精确匹配**；模糊匹配、正则匹配需要别的工具（动态规划编辑距离、NFA/DFA）。

## 常见考题
- 给定模式串，手工计算 next 数组与 nextval 数组（必考题型）。
- 模拟 KMP 匹配过程，写出失配后 j 的跳转与总的比较次数。
- 比较 BF 与 KMP 在给定主串/模式串下的比较次数差异。
- 说明 next[1] = 0 的含义，以及为什么 KMP 中主串指针不需要回溯。
