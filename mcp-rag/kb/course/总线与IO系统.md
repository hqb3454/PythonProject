# 总线与 I/O 系统（课程讲义摘要）

## 总线概述
- 总线是多个部件分时共享的公共信息通路，**同一时刻只能有一个部件发送**。
- 分类：
  - 按位置：片内总线、系统总线（数据 / 地址 / 控制）、通信总线（外总线）。
  - 按功能：数据总线（双向）、地址总线（单向，由 CPU 发出）、控制总线（双向，含中断、读写、时钟等）。
  - 按时序：同步总线（统一时钟，快但受限于最慢部件）、异步总线（握手应答，可靠但慢）。
- 性能指标：总线时钟频率、总线宽度、总线带宽 = 宽度 × 频率 × 每周期传输次数。
- 总线传输四阶段：申请分配 → 寻址 → 传数 → 结束（释放）。

## 总线仲裁
- 集中式仲裁：
  - **链式查询**：优先级固定由物理位置决定，只需 3 根控制线，但对电路故障敏感、优先级不可改。
  - **计数器定时查询**：可设定起始编号改变优先级，需要 log₂n 根地址线。
  - **独立请求**：每个设备一对请求/允许线，响应最快、优先级灵活，控制线最多（2n 根）。
- 分布式仲裁：各设备自带仲裁器比较优先级号，无需中央仲裁器。

## 总线定时
- 同步定时：统一时钟，所有事件在固定节拍发生，适合距离短、速度相近的部件。
- 异步定时：靠「请求 / 应答」握手，分不互锁、半互锁、全互锁三种，可兼容快慢设备。
- 半同步：同步为主，允许插入等待周期（WAIT）适配慢设备。

## I/O 接口
- 接口的职能：选址、传送命令、传送数据、反映设备状态、数据缓冲、格式转换（串并转换）、电平转换。
- 接口组成：数据缓冲寄存器、状态寄存器、控制寄存器、地址译码与设备选择电路。
- 端口编址：
  - **统一编址**（存储器映射）：I/O 端口占用内存地址空间，可用所有访存指令，但占用内存地址。
  - **独立编址**：单独 I/O 地址空间，需专用 IN / OUT 指令，不占内存地址但指令少。
- 端口即接口中的寄存器，一个接口通常有多个端口（数据口、状态口、命令口）。

## I/O 控制方式（重点）
| 方式 | 谁来传数据 | CPU 参与度 | 适用场景 |
|---|---|---|---|
| 程序查询 | CPU 轮询状态 | 全程占用，效率最低 | 简单慢速设备 |
| 程序中断 | CPU 执行中断服务 | 数据传送仍由 CPU 完成 | 中低速设备 |
| DMA | DMA 控制器直接传 | 仅在开始和结束时介入 | 高速块设备（磁盘） |
| 通道 | 通道处理器执行通道程序 | CPU 几乎不介入 | 大型机 |

### 中断方式
- 中断全过程：设备发请求 → CPU 在指令周期末响应 → 隐指令保存断点 → 执行中断服务程序 → 返回断点。
- 中断判优：硬件排队（链式）或查询程序；中断屏蔽字可动态改变响应优先级（注意：响应优先级与处理优先级不同）。
- 中断响应条件：有请求、CPU 开中断、当前指令执行完、无更高优先级请求（或 DMA 请求优先于中断，因为 DMA 不破坏现场且时限更紧）。

### DMA 方式
- DMA 控制器接管总线，直接在内存与外设间传送，不需要 CPU 中转寄存器。
- 三种传送方式：
  - **停止 CPU 访存**：成组传送，控制简单但 CPU 停止工作；
  - **周期挪用（窃取）**：DMA 挪用 CPU 不访存的空闲周期，最常用，CPU 仅偶有等待；
  - **交替访存**：CPU 与 DMA 分时（各半个周期），无需申请建立时间，效率最高。
- DMA 传送过程：预处理（CPU 设置内存首址、字数、方向）→ 数据传送 → 后处理（DMA 发中断，CPU 做结束处理）。
- DMA 与中断的区别：DMA 只在**一批数据传送结束**后发一次中断；中断方式每传送一个字就要中断一次。

## 重点结论
- 总线带宽计算是高频计算题，注意"每次传输字节数"与"时钟频率/周期数"的换算。
- 链式查询优先级固定且对故障敏感，独立请求速度快但线数多，这是典型的"成本换性能"权衡。
- DMA 周期挪用会让 CPU 慢一点但不会破坏现场，所以 DMA 请求的优先级高于普通中断请求。
- SPOOLing 技术把独占设备虚拟成共享设备（把磁盘当缓冲区，把要打印的数据先"假脱机"输出）。

## 常见考题
- 给定总线频率、宽度与传输模式，计算总线带宽与传输 n 字节所需时间。
- 比较链式查询、计数器定时查询与独立请求三种仲裁方式的优缺点与控制线数量。
- 比较程序查询、中断、DMA 三种方式的 CPU 占用与适用场景。
- 说明 DMA 的三种数据传送方式及其对 CPU 的影响；解释为何 DMA 优先级高于中断。
