# 动态规划（课程讲义摘要）

## 核心思想
- 适用条件：**最优子结构**（问题的最优解由子问题最优解构成）+ **重叠子问题**（子问题被反复计算）。
- 与分治的区别：分治子问题独立（如归并排序），DP 子问题重叠，用"记忆化/表格"避免重复计算。
- 与贪心的区别：贪心每步做局部最优且不回头；DP 枚举所有决策取最优，能保证全局最优。
- 设计四步法：1) 定义状态；2) 写出转移方程；3) 确定边界与计算顺序；4) （可选）记录路径还原方案。

## 0-1 背包（模板题）
- 状态：dp[i][j] = 只考虑前 i 件物品、容量为 j 时的最大价值。
- 转移：dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])——不选 / 选第 i 件。
- 空间优化：一维 dp[j]，**容量必须倒序枚举**（正序会把"每件只能选一次"破坏成完全背包）。
- 变体：完全背包（正序）、多重背包（二进制拆分）、分组背包。

## 最长上升子序列（LIS）
- O(n²) 转移：dp[i] = max(dp[j]+1)，j<i 且 a[j]<a[i]。
- O(n log n)：dp 数组存"长度为 i 的 LIS 最小结尾"，用二分/.lower_bound() 维护。

## 最长公共子序列（LCS）
- dp[i][j] 表示两串前 i、前 j 个字符的 LCS 长度。
- a[i]==b[j]：dp[i][j] = dp[i-1][j-1]+1；否则 dp[i][j] = max(dp[i-1][j], dp[i][j-1])。
- 编辑距离是 LCS 的推广：插入/删除/替换三种操作取 min。

## 重点结论
- 状态定义是 DP 的灵魂：好的状态要能"无后效性"地覆盖所有决策。
- 计算顺序由依赖决定：二维常按行列递增，背包一维优化后必须倒序。
- DP 求方案数同样适用（如爬楼梯），把 max 换成 + 即可。
- 区间 DP（如石子合并）先算小区间再合并大区间，注意区间长度作为阶段。

## 常见考题
- 0-1 背包求最大价值；若要求"恰好装满"，初始化 dp[0]=0 其余为 -∞。
- 手算 LIS 与 LCS 的 dp 表，并还原一个具体方案。
- 路径计数：m×n 网格只能右/下走，dp[i][j] = dp[i-1][j] + dp[i][j-1]。
- 判断"能否由某字符串拆成字典词"（word break）的转移与边界。
