# 数据结构 · 栈与队列（课程讲义摘要）

## 栈
- 栈是**只允许在一端（栈顶）进行插入和删除**的线性表，特点是**后进先出 LIFO**。
- 基本操作：InitStack、Push、Pop、GetTop、StackEmpty；n 个元素依次入栈，出栈序列个数为卡特兰数 `C(2n,n)/(n+1)`。
- 顺序栈：用数组 + top 指针（top 指向栈顶元素或下一个空位，两种约定需统一）；共享栈（两个栈底在数组两端，top 相向增长，提高空间利用率，栈满条件为 top1 - top0 == 1）。
- 链栈：以链表头为栈顶，入栈出栈都在表头，无需头结点时可简化；多栈共享内存更灵活。
- 出栈序列合法性判断：对给定入栈顺序，判断某出栈序列是否可能——模拟即可，也可利用"栈中元素相对顺序不变"的性质。

## 栈的应用
- 括号匹配：遇左括号入栈，遇右括号出栈并比对类型；最后栈必须为空。
- 表达式求值：
  - 中缀转后缀（逆波兰）：运算符栈，遇操作数直接输出，遇运算符与栈顶比较优先级，栈顶优先级 ≥ 当前则弹出。
  - 后缀表达式求值：操作数栈，遇运算符弹出两个操作数（注意**先弹出的是右操作数**），计算结果入栈。
  - 求值顺序陷阱：`a - b - c` 转后缀为 `a b c - -`，不能写成 `a b - c -` 再改顺序而不改变语义。
- 递归：函数调用栈保存返回地址、局部变量、寄存器现场；递归本质是栈的应用，理论上所有递归都可改写为非递归（显式栈）。
- 进制转换、迷宫求解（深度优先）、浏览器前进后退（双栈）。

## 队列
- 队列是**只允许在一端（队尾）插入、另一端（队头）删除**的线性表，特点是**先进先出 FIFO**。
- 顺序队列的**假溢出**：不断出队后数组前端有空位却判定为满。解决方法是**循环队列**。
- 循环队列：
  - 队头指针 front 指向队头元素，队尾指针 rear 指向队尾元素的**下一个位置**（约定，空一格）。
  - 队空：`front == rear`；队满：`(rear + 1) % MaxSize == front`。
  - 元素个数：`(rear - front + MaxSize) % MaxSize`。
  - 入队：`rear = (rear + 1) % MaxSize`；出队：`front = (front + 1) % MaxSize`。
  - 另一种判满方式：增设 size 变量或 tag 标志（tag=0 表示上次操作是删除导致相等，tag=1 表示插入导致相等），此时 rear 可指向队尾元素本身，不浪费空间。
- 链式队列：带头结点的单链表，front 指头结点、rear 指尾结点；出队时若删的是最后一个结点需把 rear 指回 front。

## 双端队列
- 两端都允许插入和删除；限制一端只能插入另一端可插删的称为**输入受限**双端队列，反之输出受限。
- 考点：判断给定序列能否由某类双端队列产生（模拟 + 排除法）。

## 队列的应用
- 广度优先搜索 BFS（图/树的层序遍历）。
- 缓冲区与生产者-消费者、打印队列、消息队列。
- 操作系统的作业/进程就绪队列、页面置换 FIFO 与 Clock（环形扫描）。
- 树的层次遍历（队列 + 每层结束标记可统计层号）。

## 优先队列
- 出队顺序按**优先级**而非入队时间，通常用**堆（二叉堆）**实现。
- 大顶堆：父结点 ≥ 子结点，堆顶为最大值；小顶堆反之。
- 基本操作：插入（上滤 O(log n)）、删除堆顶（下滤 O(log n)）、建堆 O(n)、堆排序 O(n log n)。
- 数组下标 i（从 1 开始）的左右孩子为 2i、2i+1，父结点为 i/2。
- 应用：Dijkstra 算法、Prim 算法、TopK 问题、事件驱动模拟、Huffman 编码。

## 栈与队列的对比
| 对比项 | 栈 | 队列 |
|---|---|---|
| 操作端 | 仅栈顶 | 队尾入、队头出 |
| 特性 | LIFO | FIFO |
| 典型应用 | 递归、括号匹配、表达式求值 | BFS、缓冲、调度 |
| 顺序实现难点 | 溢出（共享栈可缓解） | 假溢出（循环队列解决） |

## 重点结论
- 循环队列**必须浪费一个存储单元**（或用 size/tag）来区分队空与队满，否则 `front == rear` 二义。
- 栈的合法出栈序列是经典题型，三个元素的全排列中只有特定序列不合法（如 3 个元素时 `3 1 2` 不可能）。
- 递归转非递归时**必须用栈保存"返回后要继续做的事"**，不能只保存返回地址。
- 优先队列不是"先进先出"，而是"优先级高的先出"，底层几乎总是堆。

## 常见考题
- 给定入栈序列，判断哪些出栈序列合法（并给出理由）。
- 写出中缀表达式转后缀表达式的过程与最终后缀式；再给出用栈求值的步骤。
- 循环队列的队空/队满条件、元素个数公式，以及 front/rear 的初值设置。
- 设计用**两个栈实现队列**（入队压 s1，出队时若 s2 空则把 s1 全倒入 s2）或用**两个队列实现栈**。
- 给定序列，判断能否由输入受限/输出受限双端队列产生。
