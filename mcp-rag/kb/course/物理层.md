# 计算机网络 · 物理层（课程讲义摘要）

## 基本概念
- 物理层解决的是**如何在连接各种计算机的传输媒体上传输比特流**，屏蔽掉传输媒体与通信手段的差异。
- 物理层协议的四大特性（规程特性同样重要）：
  - 机械特性：接口形状、引脚数目、排列（如 RJ-45）；
  - 电气特性：线路上电压范围、阻抗匹配；
  - 功能特性：某条线上某一电平的电压表示何种意义；
  - 规程特性：事件出现的顺序。
- 数据通信模型：源系统（信源 + 发送器）→ 传输系统 → 目的系统（接收器 + 信宿）。
- 术语：数据（运送消息的实体）vs 信号（数据的电气表现）；模拟信号（连续）vs 数字信号（离散）；单向（单工）/ 双向交替（半双工）/ 双向同时（全双工）。

## 编码与调制
- 常用数字编码：
  - 不归零制 NRZ：高 1 低 0，但无法自同步（连续 0/1 时无跳变）；
  - 曼彻斯特编码：位中间跳变，上升沿为 0（或 1，取决于约定），**自含时钟**，以太网使用；
  - 差分曼彻斯特：位开始处跳变表示 0、不跳变表示 1，抗干扰更好。
- 调制：把数字信号变成模拟信号（调幅 AM、调频 FM、调相 PM；正交调幅 QAM 综合幅度与相位，提高码元信息量）。
- 码元与比特率：波特率（码元/秒）与比特率（bit/s）的关系为 `比特率 = 波特率 × log₂L`（L 为每个码元的状态数）。

## 信道的极限容量
- **奈奎斯特准则**（无噪声）：`最高码元速率 = 2W 波特`，极限数据传输率 `= 2W·log₂L (bit/s)`，W 为信道带宽（Hz）。
- **香农公式**（有噪声）：`极限速率 C = W·log₂(1 + S/N)`，S/N 为信噪比。
- 信噪比分贝值：`dB = 10·log₁₀(S/N)`，如 30 dB 表示 S/N = 1000。
- 提高速率的两条路：提高带宽 W 或提高每个码元携带的比特数（受噪声限制）。

## 传输介质
| 介质 | 特点 |
|---|---|
| 双绞线 | 便宜易安装；UTP 非屏蔽（常用超五类/六类）、STP 屏蔽抗干扰 |
| 同轴电缆 | 抗干扰强，早期局域网用，现多用于有线电视 |
| 光纤 | 多模（近距离、LED 光源）/ 单模（远距离、激光光源），带宽极高、抗电磁干扰、损耗低 |
| 无线 | 无线电波、微波、红外；易受干扰、有传播时延与多径效应 |

- 物理层设备：**中继器**（放大再生信号，延长传输距离，不隔离冲突域）、**集线器 Hub**（多口中继器，所有口共享带宽，逻辑上仍是总线，所有端口在同一冲突域）。

## 信道复用技术
- 频分复用 FDM：按频率划分子信道（广播、电视）；波分复用 WDM 是光的频分复用。
- 时分复用 TDM：按时隙划分，所有用户周期性占用；**统计时分复用 STDM** 按需动态分配时隙，利用率更高。
- 码分复用 CDM / CDMA：每个用户一个正交码片序列，靠内积分离；要求各站码片向量两两正交，抗干扰、保密性好。

## 重点结论
- 物理层不负责差错控制、不认识"帧"，它只管把 0/1 可靠地送到相邻节点。
- 曼彻斯特编码每个码元中间必跳变，所以**波特率是比特率的 2 倍**（10 Mb/s 以太网对应 20 M 波特）。
- 奈氏准则适用于无噪声理想信道，香农公式适用于有噪声真实信道，两者取较小值才是实际上限。
- 集线器不隔离冲突域也不隔离广播域；这是物理层设备与数据链路层设备（交换机）的关键区别。

## 常见考题
- 给定带宽与信噪比（dB），用香农公式求最大传输速率。
- 给定带宽与码元状态数，用奈奎斯特准则求最大码元速率与数据率。
- 画出给定比特流的曼彻斯特编码 / 差分曼彻斯特编码波形。
- 判断给定的码片序列是否正交，或从叠加信号中解出某站发送的数据。
