# 中央处理器（课程讲义摘要）

## CPU 的功能与组成
- 五大功能：指令控制、操作控制、时间控制、数据加工、中断处理。
- 基本组成：
  - 运算器：ALU + 暂存寄存器 + 累加器 / 通用寄存器组 + 状态寄存器（PSW，含 ZF/SF/CF/OF）；
  - 控制器：程序计数器 PC、指令寄存器 IR、指令译码器、时序系统、微操作信号发生器。
- 可见寄存器（用户可见）：通用寄存器、PC、PSW；**不可见**（对用户透明）：IR、MAR、MDR、暂存器。

## 指令执行过程
- 一条指令的三个阶段：**取指**（PC→MAR→存储器→MDR→IR，PC+1）→ **间址**（可选，取操作数地址）→ **执行**。
- 指令周期 = 若干个机器周期，机器周期 = 若干个时钟周期（节拍）。取指周期与执行周期的数据流是必考内容。
- 三种周期的关系：时钟周期 < 机器周期 < 指令周期。

## 数据通路
- 两类典型结构：
  - **单总线结构**：所有寄存器挂一条总线，一个节拍只能传一个数据，简单但慢；
  - **专用通路 / 多总线结构**：增加通路并行传送，速度快代价是硬件复杂。
- 关键微操作序列：如 `LOAD R1, [R2]` 需要 `(R2)→MAR`、读主存、`MDR→R1` 等若干节拍，每个节拍由控制器给出控制信号。

## 控制器的两种实现
- **硬布线控制器**：组合逻辑电路直接产生控制信号，速度快，但设计复杂、难修改，RISC 常用。
- **微程序控制器**：每条机器指令对应一段微程序，存放在控制存储器（CM，ROM）中；灵活、易扩充，CISC 常用。
  - 微指令格式：水平型（并行能力强、字长长）与垂直型（类似机器指令、字长短、并行差）。
  - 微地址形成：由微指令的下址字段给出，或用断定法（测试条件 + 转移）。
  - 执行一条机器指令 = 执行若干条微指令，每条微指令需要一个微周期。

## 指令流水线
- 经典五段：取指 IF → 译码 ID → 执行 EX → 访存 MEM → 写回 WB。
- 吞吐率提升来自时间并行：单条指令的延迟不变，但理想情况下每周期可完成约 1 条指令。
- 加速比 = `(n × k) / (k + n - 1)`（k 段、n 条指令），n 很大时趋近 k。
- 三类冒险：
  - **结构冒险**：硬件资源冲突 → 增加部件或分相位使用（如指令/数据 Cache 分离）。
  - **数据冒险**：后指令依赖前指令结果 → 转发/旁路技术、插入气泡（load-use 冒险插入 1 个气泡）。
  - **控制冒险**：分支改变 PC → 静态/动态分支预测、延迟槽、提前计算分支目标。
- 高级流水线：超标量（多发射）、超流水（细分阶段）、超长指令字 VLIW、乱序执行 + 重排序缓冲 ROB。

## 中断与异常
- 中断响应时机：CPU 在**每条指令执行周期结束时**统一查询中断请求。
- 中断隐指令（硬件自动完成）：关中断 → 保存断点（PC）与 PSW → 取中断向量 → 转入中断服务程序。
- 中断向量：每个中断源一个入口地址；向量地址可由硬件排队（菊花链）或中断控制器（8259A）给出。
- 多重中断需开中断并设置中断屏蔽字（优先级）；中断处理流程：保护现场 → 服务 → 恢复现场 → 开中断 → 返回。

## 重点结论
- 判断「哪些寄存器对用户透明」是常考陷阱：IR、MAR、MDR 一定是透明的，PC 和 PSW 不透明。
- 流水线不会缩短单条指令的执行时间，只会提高吞吐率。
- 分支预测失败要清空流水线，代价随流水线加深而增大，这也是流水线不能无限加长的原因。
- 微程序控制器中，控制存储器在 CPU 内部（不是主存），用 ROM 实现，掉电不丢失。

## 常见考题
- 写出某条指令在单总线数据通路上的微操作序列与节拍安排。
- 给定指令序列，识别结构 / 数据 / 控制冒险，并写出转发或气泡插入方案。
- 计算流水线实际吞吐率、加速比与效率。
- 说明中断隐指令完成了哪几件事，为什么必须在指令周期末响应中断。
