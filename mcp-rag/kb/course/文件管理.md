# 文件管理（课程讲义摘要）

## 文件的基本概念
- 文件是**具有符号名的、在逻辑上具有完整意义的一组信息的集合**，是外存上信息存取的基本单位。
- 文件属性：名称、类型、位置、大小、创建/修改时间、所有者、保护权限。
- 文件的逻辑结构（用户看到的）：
  - **无结构文件（流式文件）**：字节序列，如源程序、文本文件，UNIX 把所有文件都看作流式。
  - **有结构文件（记录式文件）**：由若干记录组成，分定长记录与变长记录。
- 有结构文件的组织方式：
  - 顺序文件：记录按关键字顺序排列，可顺序访问或折半查找，但增删代价高；
  - 索引文件：为每条记录建索引项，支持随机访问，索引表本身占用空间；
  - 索引顺序文件：先分组，组内顺序、组间索引，是顺序与索引的折中（如 ISAM）；
  - 直接/散列文件：按关键字哈希定位，访问最快但不支持顺序遍历。

## 目录结构
- 文件控制块 FCB：文件名 + 物理位置 + 逻辑/物理结构 + 存取权限 + 使用计数 + 时间信息；FCB 的集合就是文件目录。
- 目录结构演进：
  - 单级目录：不允许重名，查找慢，只适合单用户；
  - 两级目录：主文件目录 MFD + 用户文件目录 UFD，解决了重名与部分保护问题；
  - **多级（树形）目录**：当前最常见，用绝对路径（从根）与相对路径（从当前目录）访问；
  - 无环图目录：允许共享（同一个文件出现在多个目录中），需处理删除时的引用计数。
- **索引结点（inode）**：把文件名与文件描述信息分离，目录项只存"文件名 + inode 指针"，显著减少目录检索时的 I/O（UNIX 的做法）。

## 文件共享与保护
- 硬链接：多个目录项指向同一 inode，inode 中的链接计数 +1；删除一个链接只是计数减 1，计数为 0 才真正删除文件；不可跨文件系统、不可链接目录。
- 软链接（符号链接）：新建一个特殊文件，内容存目标路径；可跨文件系统、可链接目录，但目标删除后成为"悬空链接"。
- 文件保护：访问控制矩阵 / 精简的访问表（ACL）/ 用户-组-其他的 rwx 权限位 / 口令与加密。
- 文件系统的层次：用户调用接口 → 文件目录系统 → 存取控制模块 → 逻辑文件系统与文件信息缓冲区 → 物理文件系统。

## 外存分配方式（物理结构）
- **连续分配**：文件占一段连续磁盘块，顺序访问最快（磁头移动少）、支持随机访问；缺点是会产生外部碎片、文件长度不易动态增长。
- **链接分配**：
  - 隐式链接：每块存下一块指针，只能顺序访问，指针损坏会导致文件断裂（可靠性差）；
  - 显式链接：所有指针集中到一张**文件分配表 FAT**，常驻内存，可随机访问，FAT 方案的核心。
- **索引分配**：每个文件一张索引块，索引块中记录所有盘块号；支持随机访问，无外部碎片，但索引块本身占空间。
  - 大文件需多级索引或混合索引（UNIX inode 的**直接块 + 一级间接 + 二级间接 + 三级间接**）。
  - 混合索引的最大文件长度是必考计算：直接块数×块大小 + 一级间接 (块大小/指针大小)×块大小 + ...

## 空闲空间管理
- 空闲表法：记录每个连续空闲区的起始盘块与长度，适合连续分配。
- 空闲链表法：把空闲块串成链表，盘块链 / 成组链。
- **位示图法**：每个盘块用 1 个 bit 表示占用与否，占用空间小、易找连续空间，最常用。
- 成组链接法：UNIX 采用，把空闲盘块分组，每组的第一块记录下一组的块号，兼顾链表的灵活与表的批量分配。

## 磁盘组织与性能
- 一次磁盘读写时间 = **寻道时间**（磁头移动到目标磁道，占比最大）+ **旋转延迟**（目标扇区转到磁头下，常取半圈）+ **传输时间**。
- 优化思路：减少寻道距离（调度算法）、并行（多磁盘 RAID）、预读与缓存。
- RAID：RAID0 条带化（快但无冗余）、RAID1 镜像（可靠但容量减半）、RAID5 分布式奇偶校验（兼顾）、RAID10 先镜像再条带。

## 重点结论
- 打开文件的过程：把文件的 FCB/inode 调入内存的"打开文件表"，返回一个文件描述符；之后用描述符操作，无需每次查目录。
- 目录项与 inode 分离（文件名与元信息分离）是 UNIX 提高检索效率的关键设计。
- 硬链接删不掉源数据（只减计数），软链接删了源文件就失效——这是两者最容易被考的区别。
- 连续分配适合只读大文件（如光盘镜像），链接分配适合顺序读写，索引分配适合需要随机访问的一般文件。

## 常见考题
- 给定混合索引 inode 结构（直接块 10 个、一级/二级/三级间接各 1 个、块大小 4KB、盘块号 4B），计算最大文件长度。
- 计算某文件第 N 个字节需要访问几次磁盘（区分直接块与各级间接块）。
- 给定磁盘参数，计算访问一个块的平均时间（寻道 + 平均旋转延迟 + 传输）。
- 比较连续 / 链接 / 索引三种外存分配方式的优缺点。
- 说明硬链接与软链接在删除原文件后的行为差异。
