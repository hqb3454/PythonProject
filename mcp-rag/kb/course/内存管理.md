# 内存管理（课程讲义摘要）

## 内存管理的功能
- 内存空间的分配与回收、地址转换（逻辑地址→物理地址）、内存保护、内存扩充（虚拟内存）。
- 程序的装入：绝对装入（编译时定址）/ 可重定位装入（静态重定位，装入时一次性改地址）/ 动态运行时装入（运行时靠重定位寄存器，支持程序浮动）。
- 链接：静态链接、装入时动态链接、运行时动态链接（节省内存、便于共享与更新）。

## 连续分配管理方式
- 单一连续分配：内存分系统区与用户区，一次只装一个用户程序，最简单。
- 固定分区分配：分区大小可相等或不等，需要分区说明表，会产生**内部碎片**。
- 动态分区分配：按进程实际需要分配，产生**外部碎片**，可用"紧凑"技术解决（需动态重定位支持）。
- 动态分区分配算法：
  - 首次适应 First Fit：从低址顺序找第一个够大的，最简单最常用，低址碎片多。
  - 邻近适应 Next Fit：从上次位置继续找，分配更均匀，但可能破坏大空闲区。
  - 最佳适应 Best Fit：找最小的够用分区，保留大分区，但留下大量极小碎片。
  - 最坏适应 Worst Fit：找最大的分区，减少小碎片，但大分区易被切碎。

## 分页存储管理
- 页面（进程的逻辑块）与页框（内存的物理块）大小相同，由硬件决定，通常为 4KB。
- 逻辑地址结构：`页号 P | 页内偏移 W`；页面大小为 2^k 时，偏移占 k 位。
- 地址变换：查页表得到页框号 → 页框号 × 页面大小 + 页内偏移 = 物理地址（页框号直接拼接偏移即可）。
- 页表项：页框号 + 有效位 + 修改位 + 访问位 + 保护位；页表连续存放在内存中。
- **快表 TLB**：相联存储器缓存常用页表项，命中则一次访存即可取数据（无 TLB 时需两次访存：查页表 + 取数据）。
- 多级页表：页表本身也分页，解决"页表过大需连续存放"的问题；**顶级页表最多只能有 1 页**。
- 分页的缺点：页是物理单位，无逻辑意义，不利于共享与保护；存在页内碎片（平均半个页面）。

## 分段存储管理
- 段是**逻辑单位**（代码段、数据段、栈段），长度不固定，由用户/编译器划分，便于共享与保护。
- 逻辑地址：`段号 S | 段内偏移 W`；段表项含段长与段基址，需检查「段内偏移 < 段长」否则越界中断。
- 分段的地址变换比分页多一次越界检查；分段产生外部碎片。

## 段页式管理
- 先分段（逻辑清晰）再段内分页（物理管理方便）。
- 逻辑地址 = 段号 + 页号 + 页内偏移；每个段一张页表，访问需三次访存（段表→页表→数据），靠快表缓解。

## 虚拟内存
- 特征：多次性（分多次装入）、对换性（换入换出）、虚拟性（逻辑上扩充内存）。
- 实现基础：局部性原理 + 请求调页（缺页时才调入）+ 页面置换。
- 请求分页的页表项新增：状态位（是否在内存）、访问字段（用于置换）、修改位（是否需写回）、外存地址。
- 缺页中断：在指令执行期间产生（属于内部异常），一条指令执行期间可能发生多次缺页；缺页后 OS 阻塞该进程，调页完成后再唤醒。

### 页面置换算法
| 算法 | 规则 | 特点 |
|---|---|---|
| OPT 最佳 | 淘汰永不使用或最久不用的页面 | 理论最优，无法实现，用作评价标准 |
| FIFO | 淘汰最早进入的 | 实现简单，但存在 **Belady 异常**（分配的物理块增多，缺页率反而上升） |
| LRU 最近最少用 | 淘汰最久未访问的 | 性能好，需硬件计数器或栈支持，开销较大 |
| LFU | 淘汰访问次数最少的 | 需定期衰减，否则早期热点页面永不淘汰 |
| Clock / NRU | 环形扫描访问位，为 0 则换出，为 1 则清零 | LRU 的近似，开销小，实际系统常用 |
| 改进型 Clock | 同时考虑访问位 A 与修改位 M | 优先淘汰 (A=0,M=0)，避免频繁写回磁盘 |

- **抖动（颠簸）**：刚换出的页面马上又要换入，CPU 大量时间花在换页上。原因是分配给进程的物理块太少。
- 工作集：某段时间内进程实际访问的页面集合；分配物理块数应大于工作集大小，可避免抖动。
- 驻留集与分配策略：固定分配局部置换 / 可变分配全局置换 / 可变分配局部置换。

## 重点结论
- 分页对用户透明、一维地址；分段对用户可见、二维地址（需给出段名与段内地址）。
- 分页有内部碎片（页内），分段有外部碎片（段间）；段页式兼有但管理最复杂。
- 无快表时访存次数：分页 2 次、分段 2 次、段页式 3 次；有快表且命中时均降为 1 次。
- 有效访问时间 EAT = 命中率 × (TLB 访问 + 访存) + 未命中率 × (TLB + 查页表 + 访存)，是必考计算。
- FIFO 的 Belady 异常是唯一会出现该现象的经典算法，LRU 与 Clock 都不会（它们是栈式算法）。

## 常见考题
- 给定逻辑地址、页面大小与页表，求物理地址（并判断是否越界）。
- 计算有/无快表时的有效访问时间 EAT。
- 给定页面访问序列与物理块数，模拟 FIFO / LRU / Clock 的置换过程并统计缺页次数与缺页率。
- 说明 Belady 现象、抖动产生的原因与解决思路。
