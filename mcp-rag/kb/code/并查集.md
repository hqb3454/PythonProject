# 并查集（Union-Find）

## 思路
- 并查集维护若干个**不相交集合**，支持两个核心操作：
  - `find(x)`：查询 x 属于哪个集合（返回代表元/根结点）；
  - `union(x, y)`：把 x 和 y 所在的集合合并。
- 用森林表示集合：每个集合一棵树，根结点作为集合代表；初始时每个元素自己是根。
- 两个关键优化（缺一不可）：
  1. **路径压缩**：find 时把路径上所有结点直接挂到根下，让树高变矮；
  2. **按秩/按大小合并**：把小树挂到大树下，避免树退化成链。
- 两者结合后，单次操作的**均摊复杂度接近 O(1)**（反阿克曼函数 α(n)，实际不超过 5）。
- 典型用途：判断图中是否有环（Kruskal）、连通块计数、动态连通性问题（如"朋友圈"）、等价类划分。

## 代码

```python
from typing import List


class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))   # 父结点，根结点的父是自己
        self.size = [1] * n            # 以该结点为根的树的大小
        self.count = n                 # 连通分量个数

    def find(self, x: int) -> int:
        """路径压缩：查找根结点"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x: int, y: int) -> bool:
        """合并，返回是否真的发生了合并（False 表示本来就连通）"""
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False
        # 按大小合并：小树挂到大树下
        if self.size[rx] < self.size[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        self.size[rx] += self.size[ry]
        self.count -= 1
        return True

    def connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)

    def component_size(self, x: int) -> int:
        return self.size[self.find(x)]


def count_components(n: int, edges: List[List[int]]) -> int:
    """无向图的连通分量个数"""
    uf = UnionFind(n)
    for u, v in edges:
        uf.union(u, v)
    return uf.count


def kruskal_mst(n: int, edges):
    """最小生成树（Kruskal）：edges 为 (权重, u, v) 列表"""
    edges.sort(key=lambda e: e[0])
    uf = UnionFind(n)
    total, chosen = 0, []
    for w, u, v in edges:
        if uf.union(u, v):        # 不产生环才选这条边
            chosen.append((u, v, w))
            total += w
            if len(chosen) == n - 1:
                break
    return total, chosen


def has_cycle(n: int, edges: List[List[int]]) -> bool:
    """无向图是否有环：一条边的两点已连通则有环"""
    uf = UnionFind(n)
    for u, v in edges:
        if not uf.union(u, v):
            return True
    return False


if __name__ == "__main__":
    uf = UnionFind(5)
    uf.union(0, 1)
    uf.union(1, 2)
    print(uf.connected(0, 2))     # True
    print(uf.connected(0, 3))     # False
    print(uf.count)               # 3  即 {0,1,2} {3} {4}

    print(count_components(5, [[0, 1], [1, 2], [3, 4]]))   # 2
    print(has_cycle(3, [[0, 1], [1, 2], [2, 0]]))          # True
```

## 复杂度
- 时间：路径压缩 + 按大小合并后，find/union 的均摊复杂度为 O(α(n))，可视为 O(1)；初始化 O(n)。
- 空间：O(n)，存 parent 与 size 两个数组。
- Kruskal 整体为 O(e log e)（排序主导）。

## 易错点
- **只写路径压缩、不按大小合并**，在极端数据下仍可能退化；两个优化要一起用。
- find 必须用**递归或迭代的完整压缩**，只写 `parent[x] = parent[parent[x]]` 这类"压缩一步"的写法不够。
- `union` 返回 False 表示"两点已连通"，在图论中恰恰意味着**这条边会形成环**——不要误以为是合并失败而跳过逻辑。
- 编号问题：若题目下标从 1 开始，需开 n+1 空间或统一减 1，混用会越界。
- 并查集只能"合并"，**不能做删除或拆分**（需要删除请用可撤销并查集或线段树分治）。
- 判断"是否所有点连通"用 `uf.count == 1`，不要逐一两两比较（O(n²)）。
