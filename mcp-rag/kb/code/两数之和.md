# 两数之和

哈希表经典入门题：在数组中找和为目标值的两个数，返回下标。暴力双重循环 O(n²)；用哈希表"边查边存"一次遍历 O(n)。

```python
def two_sum(nums, target):
    seen = {}                        # 值 -> 下标
    for i, x in enumerate(nums):
        need = target - x             # 需要的搭档
        if need in seen:             # 之前出现过就是答案
            return [seen[need], i]
        seen[x] = i                   # 存下自己供后面的数查找
    return []                        # 无解
```

时间 O(n)、空间 O(n)。

## 关键思想
把"查找某个值是否存在"从 O(n) 降到 O(1)——哈希表本质是**用空间换时间**。先查再存保证不会用到同一个元素两次（自己配自己）。

## 易错点
- 先查 `need in seen` 再 `seen[x] = i`，顺序颠倒后 target=6、x=3 时会错误地返回同一个元素两次。
- 有重复值时哈希表存的是后出现的下标，查到的搭档一定是更早出现的（多数题目恰好要求这个顺序）。
- 有序数组版本可用**对撞双指针**做到 O(1) 额外空间；无序数组才必须哈希。
- 三数之和是它的扩展：排序 + 固定一个数 + 对撞指针，注意去重。
