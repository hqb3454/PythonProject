# 动态规划基础实现

两个最经典的 DP 实现：爬楼梯（计数型）与 0-1 背包（最优值型）。

## 爬楼梯
每次走 1 或 2 阶，问 n 阶有几种走法。状态 dp[i] = dp[i-1] + dp[i-2]（本质斐波那契）。

```python
def climb_stairs(n: int) -> int:
    if n <= 2:
        return n
    prev, curr = 1, 2            # 滚动变量，空间 O(1)
    for _ in range(3, n + 1):
        prev, curr = curr, prev + curr
    return curr
```

## 0-1 背包
n 件物品各有重量 w[i] 与价值 v[i]，容量 C 的背包最多能装多少价值。

```python
def knapsack(weights, values, capacity):
    dp = [0] * (capacity + 1)     # dp[j] = 容量 j 的最大价值
    for w, v in zip(weights, values):
        for j in range(capacity, w - 1, -1):   # 一维必须倒序
            dp[j] = max(dp[j], dp[j - w] + v)
    return dp[capacity]
```

## 易错点（高频考点）
- 一维背包**容量必须倒序**：正序会让同一件物品被装多次（变成完全背包）。
- dp 数组下标含义要在写代码前先定义清楚："dp[j] 表示容量恰好为 j"时初始化是 dp[0]=0 其余 -inf；"不超过 j"时全 0。
- 爬楼梯递归不带记忆化是 O(2^n)，必须加缓存或改迭代。
- 求方案数把 max 改成加法即可（dp[j] += dp[j-w]），方案数问题一般还要乘组合数。
