# 反转链表

链表经典题：把单链表方向整体反转。核心是三指针迭代法：prev / curr / nxt，逐个把 curr.next 指向前驱。

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


def reverse_list(head):
    prev, curr = None, head
    while curr:
        nxt = curr.next          # 先保存后继，否则断链
        curr.next = prev          # 反转指向
        prev = curr               # prev 前进
        curr = nxt                # curr 前进
    return prev                   # prev 是新头节点
```

递归写法（简洁但 O(n) 栈空间）：

```python
def reverse_list_rec(head):
    if not head or not head.next:
        return head
    new_head = reverse_list_rec(head.next)
    head.next.next = head         # 后继节点指回自己
    head.next = None             # 自己指向 None（新尾）
    return new_head
```

时间 O(n)，迭代版空间 O(1)。

## 易错点
- 必须先把 `curr.next` 存到 `nxt` 再改指向，直接 `curr.next = prev` 会丢失后半段链表。
- 循环结束后返回的是 `prev`（新头），返回 `curr`（None）是高频错误。
- 递归版忘记 `head.next = None` 会形成环（原来的头变成尾，必须断开）。
- 变体"区间反转 / K 个一组反转"都在这个模板上扩展，先保证基础版能默写。
