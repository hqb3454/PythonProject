# 冒泡排序与选择排序

两种最基础的 O(n²) 排序，常作为排序算法的入门对比。

## 冒泡排序
相邻两两比较，逆序就交换，每一轮把当前最大值"冒泡"到末尾。加 `swapped` 标志可在已有序时提前退出（最好情况 O(n)）。

```python
def bubble_sort(nums):
    n = len(nums)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):       # 末尾 i 个已排好，不用再比
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]
                swapped = True
        if not swapped:                   # 一轮没交换说明已有序
            break
    return nums
```

## 选择排序
每一轮从未排序区间选出最小值，与未排序区间的开头交换。

```python
def selection_sort(nums):
    n = len(nums)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if nums[j] < nums[min_idx]:
                min_idx = j
        nums[i], nums[min_idx] = nums[min_idx], nums[i]
    return nums
```

两者都是 O(n²)、原地 O(1) 空间；冒泡稳定，选择排序**不稳定**（交换会打乱相等元素顺序）。

## 易错点
- 冒泡内层边界是 `n - 1 - i`，多比较一轮是浪费但不算错；用 `range(n-1-i)` 而不是 `range(n-i-1)` 写反边界才是常见 bug。
- 选择排序交换前必须先找完最小值的下标，循环里直接交换会退化成多次无谓交换。
- 面试常问：为什么选择排序不稳定？例：[3a, 3b, 1] 第一轮 3a 与 1 交换后 3a 跑到 3b 后面。
