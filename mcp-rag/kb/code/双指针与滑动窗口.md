# 双指针与滑动窗口

## 对撞指针
有序数组中找两数之和：一头一尾向中间移动，和太小左指针右移，和太大右指针左移。

```python
def two_sum_sorted(nums, target):
    """nums 已升序，返回两个下标"""
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if s == target:
            return [left, right]
        if s < target:
            left += 1        # 和太小，换更大的左值
        else:
            right -= 1       # 和太大，换更小的右值
    return []
```

O(n) 时间、O(1) 空间。同款模板：验证回文串、盛最多水的容器、有序数组平方。

## 滑动窗口
右指针扩张探索，左指针收缩保持约束，一次遍历找"满足条件的最长/最短子串"。

```python
def longest_unique_substring(s: str) -> int:
    """最长无重复字符子串长度"""
    last = {}                 # 字符 -> 最近出现的下标
    left = ans = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1      # 左边界跳到重复字符之后
        last[ch] = right
        ans = max(ans, right - left + 1)
    return ans
```

## 易错点
- 对撞指针的条件是 `left < right`，相等时停止（不能用同一个元素）。
- 滑动窗口收缩必须是"有条件就收缩"（while），写成一个 if 会漏收缩不足的情况。
- 窗口判重必须 `last[ch] >= left`，否则历史下标会把 left 拉回左边（窗口倒退）。
- 何时用滑动窗口：元素具有单调性（右移时条件量单调变化），否则要改用别的技巧。
