# 拓扑排序

## 思路
- 拓扑排序针对**有向无环图 DAG**；在 AOV 网（顶点表示活动、有向边表示先后关系）中，它给出一个满足所有先后约束的执行顺序。
- 算法步骤（Kahn 算法）：
  1. 统计每个顶点的**入度**；
  2. 把所有入度为 0 的顶点入队；
  3. 取出队首顶点输出，删除它的所有出边（即把后继顶点的入度减 1），若某后继入度变为 0 则入队；
  4. 重复直到队列为空。
- **判环**：若最终输出的顶点数 < 顶点总数，说明图中存在环，无法进行拓扑排序。
- 另一种实现：DFS + 后序逆序（对 DAG 做 DFS，递归返回时压栈，最后逆序输出）。DFS 版还可顺便检测环（递归栈上的回边）。
- 拓扑序列**不一定唯一**：同一时刻有多个入度为 0 的顶点时，选择顺序不同结果不同；要求字典序最小则用**优先队列（最小堆）**代替普通队列。

## 代码

```python
from collections import deque
import heapq
from typing import List, Dict


def topo_sort_kahn(n: int, edges: List[List[int]]):
    """Kahn 算法（BFS）。返回拓扑序列，有环则返回 None"""
    graph = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        graph[u].append(v)
        indeg[v] += 1

    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else None


def topo_sort_lex_smallest(n: int, edges: List[List[int]]):
    """字典序最小的拓扑序列：把队列换成最小堆"""
    graph = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        graph[u].append(v)
        indeg[v] += 1

    heap = [i for i in range(n) if indeg[i] == 0]
    heapq.heapify(heap)
    order = []
    while heap:
        u = heapq.heappop(heap)
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                heapq.heappush(heap, v)
    return order if len(order) == n else None


def topo_sort_dfs(n: int, edges: List[List[int]]):
    """DFS 版：后序压栈再逆序。有环返回 None"""
    graph = [[] for _ in range(n)]
    for u, v in edges:
        graph[u].append(v)

    state = [0] * n          # 0=未访问 1=在递归栈中 2=已完成
    stack = []

    def dfs(u) -> bool:
        state[u] = 1
        for v in graph[u]:
            if state[v] == 1:
                return False          # 回边 → 有环
            if state[v] == 0 and not dfs(v):
                return False
        state[u] = 2
        stack.append(u)               # 后序压栈
        return True

    for i in range(n):
        if state[i] == 0 and not dfs(i):
            return None
    return stack[::-1]                # 逆序即拓扑序列


def has_cycle(n: int, edges: List[List[int]]) -> bool:
    """有向图是否有环"""
    return topo_sort_kahn(n, edges) is None


def course_schedule(n: int, prereq: List[List[int]]) -> bool:
    """课程表：判断能否完成所有课程。prereq[i] = [课程, 先修课]"""
    edges = [[b, a] for a, b in prereq]     # 先修课 -> 课程
    return topo_sort_kahn(n, edges) is not None


if __name__ == "__main__":
    edges = [[0, 1], [0, 2], [1, 3], [2, 3]]
    print(topo_sort_kahn(4, edges))              # [0, 1, 2, 3]（或 [0,2,1,3]）
    print(topo_sort_lex_smallest(4, edges))      # [0, 1, 2, 3]
    print(topo_sort_dfs(4, edges))               # [0, 2, 1, 3]

    print(has_cycle(3, [[0, 1], [1, 2], [2, 0]]))    # True
    print(course_schedule(2, [[1, 0]]))               # True
    print(course_schedule(2, [[1, 0], [0, 1]]))       # False（互相依赖）
```

## 复杂度
| 算法 | 时间 | 空间 | 特点 |
|---|---|---|---|
| Kahn（BFS） | O(n + e) | O(n + e) | 最常用，天然判环，可求字典序最小 |
| DFS 版 | O(n + e) | O(n) | 递归实现，可得逆拓扑序（用于关键路径求 vl） |

两者都是**每个顶点、每条边各处理一次**，线性时间。

## 易错点
- **判环必须靠"输出顶点数 < n"**，只检查"队列为空"是不够的——有环时队列也会空，只是输出的顶点更少。
- Kahn 算法要**先把所有入度为 0 的顶点一次性入队**，不是只入一个。
- 边的方向不能搞反：题目给 `[a, b]` 表示"a 必须在 b 之前"则建边 `a -> b`；若表示"学 a 要先学 b"则建边 `b -> a`（课程表题的经典陷阱）。
- DFS 版判环用**三色标记**（0/1/2），只用 visited 二色会把"已完成的顶点"误判成环。
- DFS 版的结果是**逆后序**，忘记 `stack[::-1]` 会得到反的序列。
- 要求字典序最小必须用**最小堆**，用普通队列只能得到"入队顺序"对应的序列。
- 拓扑排序只对有向图有意义；无向图判环应用并查集或 DFS 判回边。
- 拓扑序列不唯一是**正常现象**，不要以为自己的结果错了；判环才是有唯一答案的部分。
