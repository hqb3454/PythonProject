# 归并排序

归并排序是稳定的分治排序：把数组不断对半拆到单个元素，再两两合并成有序数组。合并时比较两个有序段的头部，每次取较小者。

```python
def merge_sort(nums):
    if len(nums) <= 1:
        return nums
    mid = len(nums) // 2
    left = merge_sort(nums[:mid])
    right = merge_sort(nums[mid:])
    # 合并两个有序数组
    merged, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:      # <= 保证稳定性
            merged.append(left[i]); i += 1
        else:
            merged.append(right[j]); j += 1
    merged.extend(left[i:])
    merged.extend(right[j:])
    return merged
```

时间复杂度任何情况都是 O(n log n)；需要额外 O(n) 空间。

## 易错点
- 合并时用 `<=` 取左段，否则稳定性被破坏（相等元素相对顺序会变）。
- 别忘了收尾：把剩余的 left[i:] / right[j:] 追加进去。
- Python 切片 `nums[:mid]` 会复制数组，空间翻倍；追求性能可用下标版本原地合并。
