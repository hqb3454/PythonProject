# 快速幂与最大公约数

## 思路
- **快速幂（二分幂 / 反复平方法）**：利用指数的二进制分解，`a^n = a^(2^k + ...) = a^(2^k) × ...`，把 O(n) 次乘法降到 O(log n)。
  - 迭代写法：底数不断平方 `a = a * a`，指数不断右移 `n >>= 1`，当 n 的最低位为 1 时把当前底数乘进结果。
  - 带模版本：每步取模，防止溢出，是密码学（RSA、Diffie-Hellman）与组合数取模的基础。
- **欧几里得算法（辗转相除法）**：`gcd(a, b) = gcd(b, a % b)`，直到 b 为 0。复杂度 O(log(min(a,b)))。
- **扩展欧几里得 exgcd**：在求 gcd 的同时求出 `x, y` 使 `a·x + b·y = gcd(a, b)`（裴蜀定理）。用于求**乘法逆元**、解线性同余方程。
  - 逆元存在的条件：`gcd(a, m) == 1`。
- 相关：最小公倍数 `lcm(a, b) = a / gcd(a, b) * b`（**先除后乘**防溢出）。

## 代码

```python
from typing import Tuple


def fast_pow(a: int, n: int) -> int:
    """快速幂：a^n，n 为非负整数"""
    res = 1
    while n:
        if n & 1:               # 当前二进制位为 1
            res *= a
        a *= a                  # 底数平方
        n >>= 1                 # 指数右移一位
    return res


def fast_pow_mod(a: int, n: int, mod: int) -> int:
    """带模快速幂：(a^n) % mod"""
    res = 1
    a %= mod
    while n:
        if n & 1:
            res = res * a % mod
        a = a * a % mod
        n >>= 1
    return res


def gcd(a: int, b: int) -> int:
    """欧几里得算法求最大公约数"""
    while b:
        a, b = b, a % b
    return abs(a)


def lcm(a: int, b: int) -> int:
    """最小公倍数：先除后乘避免溢出"""
    return abs(a) // gcd(a, b) * abs(b)


def exgcd(a: int, b: int) -> Tuple[int, int, int]:
    """扩展欧几里得：返回 (g, x, y) 使 a*x + b*y = g = gcd(a,b)"""
    if b == 0:
        return (abs(a), 1 if a > 0 else -1, 0)
    g, x1, y1 = exgcd(b, a % b)
    x, y = y1, x1 - (a // b) * y1
    return g, x, y


def mod_inverse(a: int, mod: int) -> int:
    """求 a 关于 mod 的乘法逆元（要求 gcd(a, mod) == 1）"""
    g, x, _ = exgcd(a, mod)
    if g != 1:
        raise ValueError("逆元不存在：a 与 mod 不互质")
    return x % mod


def solve_linear_congruence(a: int, b: int, m: int):
    """解 a*x ≡ b (mod m)，返回最小非负解，无解返回 None"""
    g, x, _ = exgcd(a, m)
    if b % g != 0:
        return None
    return (x * (b // g)) % (m // g)


def is_prime_power_check(n: int, a: int) -> bool:
    """费马小定理素性测试的辅助：a^(n-1) ≡ 1 (mod n) 是否成立"""
    return fast_pow_mod(a, n - 1, n) == 1


if __name__ == "__main__":
    print(fast_pow(2, 10))                  # 1024
    print(fast_pow_mod(2, 100, 1000000007)) # 976371285
    print(gcd(48, 18))                      # 6
    print(lcm(4, 6))                        # 12
    print(exgcd(35, 15))                    # (5, 1, -2)：35*1 + 15*(-2) = 5
    print(mod_inverse(3, 11))               # 4（3*4 = 12 ≡ 1 mod 11）
    print(solve_linear_congruence(3, 1, 11)) # 4
```

## 复杂度
| 算法 | 时间 | 空间 | 对比朴素 |
|---|---|---|---|
| 快速幂 | O(log n) | O(1) | 朴素 O(n)，n = 10⁹ 时差 10⁹ 倍 |
| 带模快速幂 | O(log n) | O(1) | 每步取模，数值不溢出 |
| gcd 辗转相除 | O(log min(a,b)) | O(1) | 朴素枚举 O(min(a,b)) |
| exgcd | O(log min(a,b)) | O(log n) 递归栈 | — |

## 易错点
- 快速幂循环体中**顺序不能变**：先判断最低位、再平方底数、最后右移指数，写反会多乘或少乘一次。
- 带模版本要先对底数取模（`a %= mod`），且每次乘法后立即取模，否则中间结果可能溢出（尤其在 C/C++/Java 中）。
- `lcm` 必须**先除后乘**：`a / gcd * b` 而不是 `a * b / gcd`，后者在大数下先溢出。
- exgcd 的递归公式 `x = y1; y = x1 - (a // b) * y1` 极易写错，尤其是 `(a // b)` 要用递归调用时的**原始 a、b**。
- 求逆元前必须确认 `gcd(a, mod) == 1`；mod 为合数时很多数没有逆元（此时可用快速幂配合欧拉定理，前提仍是互质）。
- 费马小定理求逆元只在 **mod 为质数**时成立（`a^(p-2) mod p`），mod 为合数必须用 exgcd。
- 指数为 0 时快速幂返回 1（包括 `0^0` 在此实现下为 1），与数学定义可能不符，需按题目约定处理。
- Python 的整数任意精度，但用递归 exgcd 时深度为 O(log n)，不会溢出；C 语言中要注意负数取模的结果符号不同。
