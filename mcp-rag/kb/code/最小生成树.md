# 最小生成树：Prim 与 Kruskal

## 思路
- **最小生成树 MST**：连通带权图中，包含全部 n 个顶点、n-1 条边且无环，且**边权总和最小**的生成树。
- 两者都是**贪心**且都能得到最优解，但切入口不同：
  - **Prim —— "加点"**：从任一顶点出发，每次选一条连接"已在树中的集合"与"未加入集合"的最小边，把新顶点加进来。与顶点数关系密切，**适合稠密图**。
  - **Kruskal —— "加边"**：把所有边按权值从小到大排序，依次尝试加入，若不形成环就保留。需要**并查集**判环，**适合稀疏图**。
- 记忆口诀：Prim 加点（适合稠密），Kruskal 加边（适合稀疏）。

## 代码

```python
import heapq
from typing import List, Tuple


class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y) -> bool:
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True


def prim_naive(mat: List[List[int]], start: int = 0):
    """朴素 Prim，O(n^2)，适合稠密图。无边用 float('inf')"""
    n = len(mat)
    INF = float("inf")
    dist = [INF] * n            # dist[i]：i 到当前生成树的最小边权
    visited = [False] * n
    dist[start] = 0
    total = 0
    for _ in range(n):
        u, best = -1, INF
        for i in range(n):
            if not visited[i] and dist[i] < best:
                u, best = i, dist[i]
        if u == -1:
            return INF, []      # 图不连通
        visited[u] = True
        total += best
        for v in range(n):      # 用新加入的顶点更新 dist
            if not visited[v] and mat[u][v] < dist[v]:
                dist[v] = mat[u][v]
    return total, dist


def prim_heap(graph: dict, n: int, start: int = 0):
    """堆优化 Prim，O(e log n)，适合稀疏图。graph[u] = [(v, w)]"""
    visited = [False] * n
    pq = [(0, start)]
    total, chosen = 0, []
    while pq:
        w, u = heapq.heappop(pq)
        if visited[u]:
            continue
        visited[u] = True
        total += w
        chosen.append((u, w))
        for v, ww in graph.get(u, []):
            if not visited[v]:
                heapq.heappush(pq, (ww, v))
    return total, chosen


def kruskal(edges: List[Tuple[int, int, int]], n: int):
    """Kruskal，O(e log e)。edges = [(u, v, w)]"""
    edges = sorted(edges, key=lambda e: e[2])
    uf = UnionFind(n)
    total, mst = 0, []
    for u, v, w in edges:
        if uf.union(u, v):      # 不成环才加入
            mst.append((u, v, w))
            total += w
            if len(mst) == n - 1:
                break
    return total, mst


def is_connected(edges, n: int) -> bool:
    """辅助：判断图是否连通"""
    uf = UnionFind(n)
    for u, v, _ in edges:
        uf.union(u, v)
    return len({uf.find(i) for i in range(n)}) == 1


if __name__ == "__main__":
    INF = float("inf")
    mat = [
        [0,   2,   INF, 6,   INF],
        [2,   0,   3,   8,   5],
        [INF, 3,   0,   INF, 7],
        [6,   8,   INF, 0,   9],
        [INF, 5,   7,   9,   0],
    ]
    print(prim_naive(mat, 0))        # (16, ...)

    edges = [(0, 1, 2), (0, 3, 6), (1, 2, 3), (1, 3, 8),
             (1, 4, 5), (2, 4, 7), (3, 4, 9)]
    print(kruskal(edges, 5))         # (16, [...])
    print(is_connected(edges, 5))    # True
```

## 复杂度
| 算法 | 时间 | 空间 | 适用 |
|---|---|---|---|
| Prim（朴素，邻接矩阵） | O(n²) | O(n) | **稠密图**（e ≈ n²） |
| Prim（堆优化，邻接表） | O(e log n) | O(n+e) | 稀疏图 |
| Kruskal | O(e log e) | O(n+e) | **稀疏图**（排序主导） |

选谁：边数 e 接近 n² 时用 Prim 朴素版；e 远小于 n² 时用 Kruskal。

## 易错点
- **Prim 的 dist 含义是"顶点到生成树集合的最小边权"**，不是"到起点的距离"——这与 Dijkstra 的 dist 定义完全不同，不要套用 Dijkstra 的累加写法（`dist[u] + w` 是错的，应为 `mat[u][v]`）。
- Kruskal 必须先**按边权从小到大排序**，漏了排序就完全错。
- Kruskal 判断成环要用并查集；`uf.union()` 返回 False 表示**会成环，这条边要跳过**。
- 图不连通时不存在 MST：Kruskal 的结果边数会小于 n-1，Prim 会提前遇到 `u == -1`，需要显式判断。
- 边权相同时 MST 可能有多棵（不唯一），但**最小权值和唯一**。
- 用 `float('inf')` 表示无边时，注意 `mat[u][v] < dist[v]` 的比较在 INF 下仍成立但会引入 INF 值，最好加 `if mat[u][v]` 判断。
- MST 求的是"连通所有点的最小总代价"，**不保证任意两点间路径最短**，别和最短路径混淆。
- 顶点编号从 1 开始时，并查集要开 n+1 空间。
