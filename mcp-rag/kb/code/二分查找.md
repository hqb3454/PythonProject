# 二分查找

二分查找适用于「有序数组」，每次比较中间元素，将搜索区间缩小一半，时间复杂度 O(log n)。

## Python 实现（返回目标下标，找不到返回 -1）

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

## 关键点
- 循环条件 `left <= right` 与右边界 `right = mid - 1` / `left = mid + 1` 是配套的；
- 用 `(left + right) // 2` 防溢出；
- 适用于：查找、插入位置（lower_bound）、旋转数组、峰值元素等。
