# 单调栈与单调队列

## 思路
- **单调栈**：栈内元素保持单调（递增或递减）。遇到破坏单调性的元素就弹出，直到恢复单调再入栈。
  - 核心作用：为每个元素 O(1) 找到**左边/右边第一个比它大（或小）的元素**。
  - 遍历方向决定找哪边：从左到右扫，弹出时"当前元素"就是被弹出元素**右边**第一个更大/更小的元素。
  - 典型题：每日温度（下一个更高温度）、柱状图最大矩形（找左右两侧第一个更矮的柱子）、接雨水、去除重复字母。
- **单调队列**：队列内元素保持单调，队首永远是最大/最小值。
  - 核心作用：滑动窗口的最值问题，把每窗口 O(k) 的扫描降到**均摊 O(1)**。
  - 实现要点：新元素入队前从队尾弹出所有"比它小（求最大值时）"的元素；队首元素滑出窗口时出队。
  - 队列中存**下标**而非值，这样才能判断元素是否已滑出窗口。

## 代码

```python
from collections import deque
from typing import List


def next_greater_element(nums: List[int]) -> List[int]:
    """单调栈（递减栈）：求每个元素右边第一个更大元素的下标，没有则为 -1"""
    n = len(nums)
    res = [-1] * n
    stack = []                       # 存下标，对应的值单调递减
    for i in range(n):
        while stack and nums[i] > nums[stack[-1]]:
            res[stack.pop()] = i     # 当前 i 就是被弹出元素右边第一个更大元素
        stack.append(i)
    return res


def daily_temperatures(t: List[int]) -> List[int]:
    """每日温度：还要等多少天才能等到更暖的一天"""
    n = len(t)
    res = [0] * n
    stack = []
    for i in range(n):
        while stack and t[i] > t[stack[-1]]:
            j = stack.pop()
            res[j] = i - j
        stack.append(i)
    return res


def largest_rectangle_area(heights: List[int]) -> int:
    """柱状图最大矩形：找每个柱子左右第一个更矮的柱子"""
    h = heights + [0]                # 哨兵：强制清空栈
    stack = []                       # 存下标，高度单调递增
    best = 0
    for i in range(len(h)):
        while stack and h[i] < h[stack[-1]]:
            cur = stack.pop()
            left = stack[-1] if stack else -1   # 左边更矮的柱子位置
            width = i - left - 1
            best = max(best, h[cur] * width)
        stack.append(i)
    return best


def max_sliding_window(nums: List[int], k: int) -> List[int]:
    """单调队列：滑动窗口最大值"""
    q = deque()                      # 存下标，对应的值单调递减
    res = []
    for i, x in enumerate(nums):
        while q and nums[q[-1]] <= x:
            q.pop()                  # 队尾比 x 小的不可能成为最大
        q.append(i)
        if q[0] <= i - k:            # 队首已滑出窗口
            q.popleft()
        if i >= k - 1:               # 形成完整窗口后才输出
            res.append(nums[q[0]])
    return res


if __name__ == "__main__":
    print(next_greater_element([2, 1, 2, 4, 3]))    # [3, 2, 3, -1, -1]
    print(daily_temperatures([73, 74, 75, 71, 69, 72, 76, 73]))
    print(largest_rectangle_area([2, 1, 5, 6, 2, 3]))   # 10
    print(max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3))  # [3,3,5,5,6,7]
```

## 复杂度
| 算法 | 时间 | 空间 | 说明 |
|---|---|---|---|
| 单调栈 | O(n) | O(n) | 每个元素**最多入栈出栈各一次**，虽然有 while 但不是 O(n²) |
| 单调队列 | O(n) | O(k) | 每个元素最多进出队列各一次，均摊 O(1) |
| 暴力滑动窗口最值 | O(n·k) | O(1) | 对比：单调队列把 k 这个因子消掉 |

## 易错点
- 看到 `while stack and ...` 就以为是 O(n²)：**每个元素最多被弹出一次**，总复杂度仍是 O(n)，这是单调类算法的关键。
- 比较符号写反会导致求成"更小"而非"更大"：求**下一个更大**用递减栈（大元素来了就弹小的）；求**下一个更小**用递增栈。
- 存**下标**而不是存值，否则无法计算距离、宽度或判断元素是否滑出窗口。
- 单调队列的两步清理顺序不能颠倒：**先从队尾弹出小的，再判队首是否过期**，最后才取队首输出。
- 窗口输出时机：`i >= k - 1` 才开始收集结果，否则前 k-1 个不完整窗口会被误输出。
- 柱状图最大矩形中**哨兵 0** 是简化写法的关键，省去遍历结束后单独清空栈的代码；左边边界用 `stack[-1] if stack else -1` 处理"左边没有更矮柱子"的情况。
- 求最大值用递减队列、求最小值用递增队列，写反会完全错。
