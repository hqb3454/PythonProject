# 堆排序

堆排序利用完全二叉树的堆性质：先自底向上建大顶堆，然后反复"堆顶（最大值）与末尾交换、堆大小减一、下滤修复"。

```python
def heap_sort(nums):
    n = len(nums)

    def sift_down(start, end):
        """下滤：把 nums[start] 下移到 end 范围内的正确位置"""
        root = start
        while True:
            child = 2 * root + 1          # 左孩子下标
            if child > end:
                break
            if child + 1 <= end and nums[child + 1] > nums[child]:
                child += 1                # 选更大的孩子
            if nums[root] < nums[child]:
                nums[root], nums[child] = nums[child], nums[root]
                root = child
            else:
                break

    # 1) 建大顶堆：从最后一个非叶子节点开始
    for i in range(n // 2 - 1, -1, -1):
        sift_down(i, n - 1)
    # 2) 排序：堆顶(最大)换到末尾，缩短堆并修复
    for end in range(n - 1, 0, -1):
        nums[0], nums[end] = nums[end], nums[0]
        sift_down(0, end - 1)
    return nums
```

时间复杂度 O(n log n)，原地排序、空间 O(1)，不稳定。

## 易错点
- 建堆从 `n//2 - 1`（最后一个非叶子）开始倒序下滤，不是从 0 正序。
- 下滤要选**更大的那个孩子**（大顶堆），写反会得到小顶堆。
- 排序阶段交换后堆大小是 `end - 1`，不要把已排好的尾部再纳入下滤。
- Python 有现成的 `heapq`（小顶堆），但那是"优先队列"用法；堆排序考察的是手写下滤过程。
