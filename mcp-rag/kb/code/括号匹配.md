# 括号匹配

用栈解决括号合法性判断：左括号入栈，右括号必须与栈顶左括号配对弹出；最后栈为空才合法。

```python
def is_valid_parentheses(s: str) -> bool:
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in '([{':                  # 左括号入栈
            stack.append(ch)
        elif ch in pairs:                # 右括号检查栈顶
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack                     # 栈空才完全匹配
```

时间 O(n)、空间 O(n)。这是"栈"结构最典型的应用场景，也常扩展为"合法括号串的生成"（回溯）或"最长有效括号"（DP/栈）。

## 易错点
- 右括号出现时栈可能已空，必须先判断 `not stack` 再 pop，否则 IndexError 或逻辑漏判。
- 结尾必须检查 `return not stack`，只遍历完不够（可能剩左括号，如 "(("）。
- 常见变体：判断含有其他字符的字符串、只含一种括号时可用计数器（遇右括号时计数为 0 即非法）。
- 与"表达式求值"同源：双栈（数字栈 + 运算符栈）处理优先级是它的进阶。
