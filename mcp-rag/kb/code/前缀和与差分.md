# 前缀和与差分

## 思路
- **前缀和**：预处理 `s[i] = a[0] + ... + a[i-1]`（长度 n+1，s[0] = 0），任意区间 `[l, r]` 的和为 `s[r+1] - s[l]`，把区间查询从 O(n) 降到 O(1)。
- **差分**：前缀和的逆运算。`d[0] = a[0]`，`d[i] = a[i] - a[i-1]`。对区间 `[l, r]` 整体加 v 只需 `d[l] += v; d[r+1] -= v`，最后对 d 求前缀和还原数组。把区间修改从 O(n) 降到 O(1)。
- 记忆口诀：**多次查询用前缀和，多次修改用差分**；两者都是"用预处理换时间"。
- 二维扩展：二维前缀和 `s[i][j]` 用容斥计算，子矩阵和同样用容斥相减。

## 代码

```python
from typing import List


class PrefixSum:
    """一维前缀和：支持 O(1) 区间求和"""

    def __init__(self, a: List[int]):
        self.s = [0] * (len(a) + 1)
        for i, x in enumerate(a):
            self.s[i + 1] = self.s[i] + x

    def query(self, l: int, r: int) -> int:
        """闭区间 [l, r] 的和"""
        return self.s[r + 1] - self.s[l]


class Diff:
    """一维差分：支持 O(1) 区间加"""

    def __init__(self, a: List[int]):
        n = len(a)
        self.d = [0] * (n + 1)
        self.d[0] = a[0]
        for i in range(1, n):
            self.d[i] = a[i] - a[i - 1]

    def add(self, l: int, r: int, v: int) -> None:
        """闭区间 [l, r] 每个元素加 v"""
        self.d[l] += v
        self.d[r + 1] -= v

    def result(self) -> List[int]:
        """还原最终数组"""
        res = [0] * (len(self.d) - 1)
        cur = 0
        for i in range(len(res)):
            cur += self.d[i]
            res[i] = cur
        return res


def subarray_sum_count(nums: List[int], k: int) -> int:
    """和为 k 的子数组个数（前缀和 + 哈希表，可处理负数）"""
    from collections import defaultdict
    cnt = defaultdict(int)
    cnt[0] = 1          # 前缀和为 0 出现过一次
    ans = s = 0
    for x in nums:
        s += x
        ans += cnt[s - k]   # 之前有多少个前缀和等于 s-k
        cnt[s] += 1
    return ans


def matrix_prefix(mat: List[List[int]]):
    """二维前缀和：返回 s，s[i][j] 为左上角 (0,0) 到 (i-1,j-1) 的和"""
    m, n = len(mat), len(mat[0])
    s = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            s[i][j] = (mat[i - 1][j - 1] + s[i - 1][j]
                       + s[i][j - 1] - s[i - 1][j - 1])
    return s


def matrix_query(s, r1, c1, r2, c2) -> int:
    """子矩阵 (r1,c1) 到 (r2,c2) 的和，闭区间"""
    return (s[r2 + 1][c2 + 1] - s[r1][c2 + 1]
            - s[r2 + 1][c1] + s[r1][c1])


if __name__ == "__main__":
    a = [1, 3, 5, 7, 9]
    ps = PrefixSum(a)
    print(ps.query(1, 3))        # 15 = 3+5+7

    d = Diff(a)
    d.add(1, 3, 10)
    print(d.result())            # [1, 13, 15, 17, 9]

    print(subarray_sum_count([1, 1, 1], 2))   # 2
```

## 复杂度
| 操作 | 朴素 | 前缀和/差分 |
|---|---|---|
| 区间求和 | O(n) | O(1)（预处理 O(n)） |
| 区间整体加 | O(n) | O(1)（还原 O(n)） |
| 和为 k 的子数组 | O(n²) | O(n) |

空间复杂度均为 O(n)。

## 易错点
- 下标对齐：前缀和数组长度是 n+1 且 `s[0] = 0`，查询 `[l, r]` 用 `s[r+1] - s[l]`，混用 n 长度数组会导致差一错误。
- 差分的 `[r+1] -= v` 索引可能等于 n，所以差分数组要开 n+1 或特判 `r+1 == n`。
- 一维前缀和只能处理"静态数组"（中途不修改）；若既要修改又要查询，应改用树状数组或线段树。
- `subarray_sum_count` 中 `cnt[0] = 1` 不能漏，否则从下标 0 开始的子数组会被漏计。
- 二维前缀和的四项容斥容易写错顺序，记口诀：**加左上、减上、减左、加左上角**。
- 前缀和可能溢出：Python 无此问题，C/C++ 中大量数据需用 long long。
